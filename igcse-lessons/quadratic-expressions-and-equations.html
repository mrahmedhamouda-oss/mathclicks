Expanding, factorising and solving quadratics — and reading the answers straight off the parabola that goes with them.

1 ·  What makes an expression quadratic

An expression is quadratic when the highest power of the variable is 2 — there is an x² term and nothing higher. That single fact controls everything else in this lesson: a quadratic equation usually has two solutions, and its graph is a curve, not a line.

Definition A quadratic expression can always be written as ax² + bx + c with a ≠ 0. So 5 − 2x² is quadratic (a = −2, b = 0, c = 5), but 4x − 9 is linear and x³ + x² is cubic.

Multiplying two linear brackets always produces a quadratic. Multiply every term in the first bracket by every term in the second, then collect the two middle terms.

(x + p)(x + q) = x² + (p + q)x + pq The middle coefficient is the sum, the constant is the product
Example 1Expand and simplify (2x − 3)(x + 5).
1
Multiply the first term of the left bracket by both terms of the right bracket. 2x × x = 2x²    2x × 5 = 10x
2
Now the second term, keeping its minus sign. −3 × x = −3x    −3 × 5 = −15
3
Write all four terms out and collect the like terms. 2x² + 10x − 3x − 15 = 2x² + 7x − 15
(2x − 3)(x + 5) = 2x² + 7x − 15
Exam tip Check with a quick substitution. At x = 1 the brackets give (−1)(6) = −6 and the answer gives 2 + 7 − 15 = −6. Same value, so the expansion is almost certainly right.

2 ·  Factorising a quadratic

Factorising is expanding run backwards. Because the middle coefficient is the sum and the constant is the product, the whole job is: find two numbers that multiply to c and add to b. The signs of b and c tell you the signs inside the brackets before you hunt for numbers.

Sign of cSign of bSigns in the bracketsExample
positivepositiveboth +x² + 7x + 12 = (x + 3)(x + 4)
positivenegativeboth −x² − 7x + 12 = (x − 3)(x − 4)
negativepositiveone of each; the larger number is +x² + x − 12 = (x + 4)(x − 3)
negativenegativeone of each; the larger number is −x² − x − 12 = (x − 4)(x + 3)
Note When c is negative the two numbers have opposite signs, so you are looking for a difference of b, not a sum.
Example 2Factorise (a) x² − 9x + 20  (b) x² + 2x − 15.
1
(a) c = +20 and b = −9, so both brackets are negative. Pairs multiplying to 20: 1×20, 2×10, 4×5; the pair adding to 9 is 4 + 5. x² − 9x + 20 = (x − 4)(x − 5)
2
(b) c = −15, so one bracket is plus and one is minus. The difference must be 2, so use 5 and 3; b is positive, so the plus goes on the 5. x² + 2x − 15 = (x + 5)(x − 3)
(a) (x − 4)(x − 5)    (b) (x + 5)(x − 3)
Exam tip Expand your answer mentally before moving on. For (b): x² − 3x + 5x − 15 = x² + 2x − 15 ✓.

When there is no x term and the constant is subtracted, a special pattern factorises instantly — it appears in almost every paper, often disguised.

a² − b² = (a + b)(a − b) The difference of two squares
Example 3Factorise completely (a) x² − 49  (b) 9x² − 25  (c) 2x² − 50.
1
(a) Write both parts as squares: x² and 49 = 7². x² − 49 = (x + 7)(x − 7)
2
(b) 9x² = (3x)² and 25 = 5². 9x² − 25 = (3x + 5)(3x − 5)
3
(c) Neither 2 nor 50 is a square — but there is a common factor of 2. Take it out first, then use the pattern. 2x² − 50 = 2(x² − 25) = 2(x + 5)(x − 5)
(a) (x + 7)(x − 7)   (b) (3x + 5)(3x − 5)   (c) 2(x + 5)(x − 5)
Watch out x² + 49 does not factorise — only a difference of squares splits into brackets. The word “completely” in a question is a strong hint that a common factor comes out first.

3 ·  Solving by factorising

The zero-product principle If A × B = 0 then A = 0 or B = 0. Two numbers can only multiply to zero if at least one of them is zero.

The method, every time

  1. Rearrange so one side reads ax² + bx + c and the other side is 0.
  2. Factorise the left-hand side.
  3. Set each bracket equal to zero and solve the two little linear equations.
  4. State both answers, using the word “or”.
Example 4Solve (a) x² + 3x − 10 = 0  (b) x² + 5x = 24.
1
(a) Already equal to zero. Product −10, sum +3: the pair is +5 and −2. (x + 5)(x − 2) = 0
2
Set each bracket to zero. x + 5 = 0  →  x = −5
x − 2 = 0  →  x = 2
3
(b) This one is not equal to zero yet. Subtract 24 from both sides first. x² + 5x − 24 = 0
4
Product −24, sum +5: the pair is +8 and −3. (x + 8)(x − 3) = 0  →  x = −8  or  x = 3
5
Check in the original form x² + 5x = 24. (−8)² + 5(−8) = 64 − 40 = 24 ✓
3² + 5(3) = 9 + 15 = 24 ✓
(a) x = −5 or x = 2     (b) x = −8 or x = 3

Equations like x² = 5x tempt everybody. Dividing both sides by x gives x = 5 and looks finished — but you have divided by something that might be zero and thrown away the root x = 0. Examiners set this deliberately.

x² = 5x  →  x² − 5x = 0  →  x(x − 5) = 0  →  x = 0  or  x = 5 Move everything to one side and take out the common factor x

4 ·  The graph y = ax² + bx + c

Every quadratic graph is a parabola: a smooth, symmetrical curve with one turning point. The solutions of ax² + bx + c = 0 are exactly the x-coordinates where the curve crosses the x-axis, because that is where y = 0.

What each letter does

  • a > 0: U-shaped with a minimum; a < 0: upside down with a maximum.
  • c is the y-intercept: the curve passes through (0, c).

Symmetry and roots

  • The line of symmetry is vertical, halfway between the roots: x = −b2a.
  • Roots are also called zeros or x-intercepts — three names for the same thing.

How many times can a parabola meet the x-axis?

A quadratic that will not factorise is usually one whose curve either misses the axis altogether or cuts it at values that are not whole numbers.

1

perimeter = 22 cm

Common mistakes Lose no easy marks

Using the brackets when the right-hand side is not zero If (x + 1)(x + 2) = 6 you may not write x + 1 = 6 or x + 2 = 6. The zero-product principle only works against zero — expand, take the 6 across, and start again.
Dividing both sides by x For x² = 5x, dividing by x loses the root x = 0. Take x out as a factor instead — a two-mark quadratic nearly always wants two answers.
Factorising a sum of squares x² + 49 does not factorise. Only a difference of two squares splits as (a + b)(a − b).
Exam tip After factorising, expand mentally to check; after solving, substitute both roots back into the original equation. Each check costs seconds and protects the accuracy marks.
