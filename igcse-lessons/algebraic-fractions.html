Algebraic Fractions

Fractions with algebra on top, underneath, or both — learn to simplify, combine and solve them, with one golden rule: factorise before you cancel.

← All lessons Objectives Starter Learn Practice Mistakes Exit check

Learning objectives What you will be able to do

  • Simplify an algebraic fraction by factorising the top and bottom fully, then cancelling common factors.
  • Multiply and divide algebraic fractions, inverting the second fraction to divide.
  • Add and subtract algebraic fractions using a common denominator, bracketing the second numerator when subtracting.
  • Solve equations containing algebraic fractions, stating and rejecting any excluded values.

1 ·  Cancel factors, never terms

An algebraic fraction is a fraction with algebra on the top, the bottom, or both. Everything you know about ordinary fractions still applies — the only new skill is that you must factorise before you can cancel.

The golden rule You may cancel a factor that multiplies the whole of the top and the whole of the bottom. You may never cancel a term — something that is only part of a sum.

Allowed — cancelling a factor

3(x + 2)(x + 2)(x + 3) = 3x + 3

The bracket (x + 2) multiplies everything above and everything below, so it divides out.

Not allowed — cancelling a term

x + 3x + 6 ≠ 12

The 3 and the 6 are joined on by +, not ×. Try x = 5: the left side is 8/11 = 0.727…, not 0.5.

Method Factorise the numerator fully, factorise the denominator fully, then cancel any bracket (or number) that appears in both. If nothing factorises, the fraction is already in its simplest form.
Example 1Simplify (a) x² − 9x² + 7x + 12  (b) 3x + 6x² + 5x + 6
1
(a) Factorise top and bottom — the starter did both for you. (x − 3)(x + 3)(x + 3)(x + 4)
2
Cancel the common factor (x + 3). = x − 3x + 4
3
(b) Take out the numerical factor on top; factorise the bottom. 3(x + 2)(x + 2)(x + 3) = 3x + 3
(a) x − 3x + 4     (b) 3x + 3
Exam tip Test with a number. In (a), put x = 1: original = −8/20 = −0.4; answer = −2/5 = −0.4. Equal, so the cancelling was legal.

2 ·  Multiplying and dividing

These are the easy operations — no common denominator is needed. Factorise everything first, cancel any top against any bottom across the multiplication, then write what is left.

ab × cd = acbd      ab ÷ cd = ab × dc To divide, turn the second fraction upside down and multiply
Example 2Simplify x² − 4x + 1 × 3x + 3x − 2
1
Factorise every top and every bottom. (x − 2)(x + 2)x + 1 × 3(x + 1)x − 2
2
Cancel (x − 2) and (x + 1) across the multiplication. = (x + 2) × 3
3(x + 2)   (or equivalently 3x + 6)
Check At x = 5 the original is (21 ÷ 6) × (18 ÷ 3) = 3.5 × 6 = 21, and 3(5 + 2) = 21. ✓
Example 3Simplify x² + 5x + 6x² − 1 ÷ x + 3x − 1
1
Turn the second fraction upside down and change ÷ to × — before any cancelling. x² + 5x + 6x² − 1 × x − 1x + 3
2
Now factorise everything. (x + 2)(x + 3)(x − 1)(x + 1) × x − 1x + 3
3
Cancel (x + 3) and (x − 1). = x + 2x + 1
x + 2x + 1
Watch out Invert only the fraction after the division sign. Cancelling across a ÷ sign is not allowed — invert first, then cancel.

3 ·  Adding and subtracting

Fractions can only be added when they have the same denominator. With algebra the safe common denominator is the product of the two denominators — unless they share a factor, in which case factorise first and use the smaller one.

ax + p + bx + q = a(x + q) + b(x + p)(x + p)(x + q) Cross-multiply the tops; multiply the bottoms
Watch out When you subtract, the whole of the second numerator is being taken away, so put it in a bracket: a(x + q) − b(x + p). Forgetting to change the sign of the second term inside that bracket is the classic lost mark.
Example 4Write as a single fraction (a) xx + 1 + 3x − 2  (b) 3x − 1 − 2x + 4
1
(a) The common denominator is (x + 1)(x − 2). Multiply each numerator by the denominator it is missing. x(x − 2) + 3(x + 1)(x + 1)(x − 2)
2
Expand the top only — leave the bottom factorised. x² − 2x + 3x + 3 = x² + x + 3
3
(b) Same start, but subtract — and bracket the second numerator. 3(x + 4) − 2(x − 1)(x − 1)(x + 4)
4
Expand carefully: −2 × (−1) = +2. 3x + 12 − 2x + 2 = x + 14
(a) x² + x + 3(x + 1)(x − 2)     (b) x + 14(x − 1)(x + 4)
Check with a number (b) at x = 5: 3 ÷ 4 − 2 ÷ 9 = 0.5278…, and 19 ÷ 36 = 0.5278… ✓

4 ·  Equations containing algebraic fractions

To solve an equation with fractions in it, multiply every term by the common denominator. The fractions disappear and you are left with a linear or a quadratic equation you already know how to solve.

Values that are not allowed A denominator can never be zero. Before you start, write down the excluded values of x: for 5x + 2 that is x ≠ −2. If a solution turns out to be an excluded value, reject it.
Example 5Solve 1x + 1x + 1 = 56
1
State the excluded values first. x ≠ 0  and  x ≠ −1
2
The common denominator of all three terms is 6x(x + 1). Multiply every term by it and cancel. 6(x + 1) + 6x = 5x(x + 1)
3
Expand both sides and collect on the side that keeps x² positive. 12x + 6 = 5x² + 5x  →  0 = 5x² − 7x − 6
4
Factorise: ac = −30, sum −7, so split with −10 and 3. 5x² − 10x + 3x − 6 = (x − 2)(5x + 3) = 0
5
Solve each bracket. Neither value is excluded, so keep both. x = 2  or  x = −35
x = 2  or  x = −0.6
Check both ½ + ⅓ = 5/6 ✓ and at x = −0.6: −1.6̇ + 2.5 = 0.83̇ = 5/6 ✓

Practice Now you try

Do every question on paper first, then open the solution and mark your own working.

Practice 1Simplify x² − 16x² − x − 12.
1
Factorise both. On the bottom: product −12, sum −1 → −4 and 3. (x − 4)(x + 4)(x − 4)(x + 3)
2
Cancel the common factor (x − 4).
x + 4x + 3
Practice 2Write as a single fraction: 2x + 3 + 5x − 1.
1
Common denominator (x + 3)(x − 1); cross-multiply the tops. 2(x − 1) + 5(x + 3) = 2x − 2 + 5x + 15 = 7x + 13
7x + 13(x + 3)(x − 1)
Practice 3Simplify x² − 1x + 2 × 3x + 6x − 1.
1
Factorise, then cancel (x + 2) and (x − 1). (x − 1)(x + 1)x + 2 × 3(x + 2)x − 1 = 3(x + 1)
3(x + 1)
Practice 4Solve x + 12x = 8.
1
Multiply every term by x (with x ≠ 0). x² + 12 = 8x  →  x² − 8x + 12 = 0
2
Factorise and solve. (x − 2)(x − 6) = 0
x = 2  or  x = 6
Practice 5Solve 5x − 1 − 2x + 2 = 1, giving your answers correct to 2 decimal places.
1
Excluded values: x ≠ 1, x ≠ −2. Multiply every term by (x − 1)(x + 2). 5(x + 2) − 2(x − 1) = (x − 1)(x + 2)
2
Expand both sides. 3x + 12 = x² + x − 2  →  x² − 2x − 14 = 0
3
No integer pair works, so use the quadratic formula with a = 1, b = −2, c = −14. x = 2 ± √602 = 1 ± √15
x = 4.87  or  x = −2.87  (2 d.p.)

Common mistakes Lose no easy marks

Cancelling terms instead of factors x + 3x + 6 does not simplify to 12. Nothing can be cancelled until the top and the bottom are written as products — factorise first, cancel second.
Losing a sign when subtracting In a(x + q) − b(x + p) the subtraction applies to the whole second numerator. Bracket it before expanding, or the sign of its second term will be wrong.
Ignoring excluded values A denominator can never be zero. State the forbidden values of x at the start of any equation, and reject a solution that matches one of them.
Exam tip Check simplifications and solutions by substituting a number. At x = 5, the original expression and your answer must give the same value — twenty seconds that can save several marks.

Exit check Prove it before you leave

Exit 1Simplify 5(x + 1)(x + 1)(x − 2).
5x − 2 — the factor (x + 1) cancels.
Exit 2True or false: x + 2x + 4 simplifies to 12.
False — the 2 and 4 are terms, not factors; the fraction is already in its simplest form.
Exit 3Which value of x is not allowed in 7x − 3?
x = 3 — it would make the denominator zero.
