Sequences

Term-to-term and position-to-term rules, the nth term of linear and quadratic sequences, and how to spot geometric and Fibonacci-style patterns.

Learning objectives What you will be able to do

  • Tell the difference between a term-to-term rule and a position-to-term rule (the nth term).
  • Find the nth term of any linear sequence using dn + (a − d).
  • Find the nth term of a quadratic sequence from its second differences.
  • Recognise geometric and Fibonacci-style sequences and continue them.
  • Test whether a given number is a term of a sequence, with a written reason.

1 ·  Two kinds of rule

A sequence is a list of numbers in a definite order. Each number is a term, and each term has a position — we write the term in position n as Tn. There are two ways to describe a sequence:

Term-to-term rule

Tells you how to get from one term to the next, and must come with the first term.

3, 7, 11, 15, … — “start at 3 and add 4 each time.”

Fine for the 6th term; hopeless for the 200th.

Position-to-term rule

A formula in n that gives any term straight away — this is what examiners mean by “find the nth term”.

Tn = 4n − 1:  n = 1 gives 3, n = 200 gives 799 — one substitution, no listing.

Watch out “Add 4 each time” earns no marks when the question asks for the nth term. The answer must be an expression containing n, and positions always start at n = 1, never 0.

2 ·  Linear sequences

A sequence is linear when the difference between consecutive terms is always the same. Call that common difference d and the first term a.

nth term = dn + (a − d) d = common difference  ·  a = first term

The coefficient of n must be d, because each step of 1 in position adds d to the value; a − d is the “zero term” that would sit in front of the first term.

Example 1Find the nth term of 5, 8, 11, 14, … and hence the 50th term.
1
Write the differences underneath — they are constant, so the sequence is linear. 5   8   11   14
  +3  +3  +3  →  d = 3
2
Use dn + (a − d) with a = 5, d = 3. Tn = 3n + (5 − 3) = 3n + 2
3
Check before moving on. 3(1) + 2 = 5 ✓    3(4) + 2 = 14 ✓
4
Substitute n = 50. T50 = 3(50) + 2 = 152
Tn = 3n + 2   ·   T50 = 152

To test whether a value is a term, set the nth term equal to it and solve. If n comes out a positive whole number, it is a term and n tells you which; a fraction or a negative means it never appears.

Example 2A sequence begins 20, 17, 14, 11, … (a) Find the nth term. (b) Is −7 a term? (c) Is 0 a term?
1
(a) The difference is negative but still constant. d = −3,   a = 20
Tn = −3n + (20 − (−3)) = 23 − 3n
2
(b) Set the rule equal to −7 and solve. 23 − 3n = −7  →  3n = 30  →  n = 10
3
(c) Now try 0. 23 − 3n = 0  →  n = 23/3 = 7.67… Not a whole number, so 0 never appears.
(a) 23 − 3n    (b) yes — the 10th term    (c) no
Exam tip Write the sentence “n is not a positive integer, so it is not a term”. The reasoning carries the mark, not just the word “no”.

Pattern questions are linear sequences in disguise — count the matches or shapes, list the numbers, then use the same method. The common difference is whatever each new copy of the pattern adds.

Squares made from matchsticks

Counts: 4, 7, 10, … so d = 3, a = 4 and pattern n uses 3n + 1 matches — one match to start the row, then 3 per square.

3 ·  Quadratic sequences

If the first differences are not constant, difference them again. When the second differences are constant, the sequence is quadratic: its nth term has the form an² + bn + c.

a = second difference2 then subtract an² from the sequence and finish with the linear method

The three-step method

  1. Second difference ÷ 2 gives a.
  2. Work out an² for n = 1, 2, 3, … and subtract it from the original terms.
  3. What is left is always linear — find its rule bn + c and add it on.
Example 3A sequence is 3, 8, 15, 24, 35, … (a) Find the nth term. (b) Show that 168 is a term and say which one.
1
Build the difference table. terms:  3   8   15   24   35
1st:    5   7    9    11
2nd:     2   2    2
2
Second difference 2, so a = 2 ÷ 2 = 1. Subtract n² from the terms. n²: 1, 4, 9, 16, 25
left over: 2, 4, 6, 8, 10
3
The leftover is linear with d = 2, first term 2, so it is 2n. Add the parts and check n = 4. Tn = n² + 2n    (16 + 8 = 24 ✓)
4
(b) Solve n² + 2n = 168 as a quadratic. n² + 2n − 168 = 0
(n + 14)(n − 12) = 0  →  n = −14 or n = 12 A position must be positive, so n = 12.
(a) Tn = n² + 2n   ·   (b) 168 is the 12th term
Watch out Do not stop at the second difference and write “a = 2”. You must halve it — the single most-forgotten step in this topic.

4 ·  Geometric and Fibonacci-style sequences

Geometric sequences

You multiply by a constant ratio r each time, so differencing never settles. Divide consecutive terms to find r.

Tn = ar n−1 — the power is n − 1, so that n = 1 returns the first term.

Fibonacci-style sequences

Each term is the sum of the two before it: Tn+2 = Tn+1 + Tn, as in 1, 1, 2, 3, 5, 8, 13, …

Questions ask you to continue the sequence or find a missing early term with algebra — there is no simple nth term at IGCSE.

Example 4A sequence is 5, 10, 20, 40, … (a) Write down the nth term. (b) Find the 10th term. (c) Which term equals 1280?
1
Each term is double the one before. 10 ÷ 5 = 2,   20 ÷ 10 = 2  →  r = 2, a = 5
2
(a) Use ar n−1. Tn = 5 × 2 n−1
3
(b) Substitute n = 10 — the power is 9, not 10. T10 = 5 × 29 = 5 × 512 = 2560
4
(c) Solve 5 × 2 n−1 = 1280. 2 n−1 = 256 = 28  →  n = 9
(a) 5 × 2 n−1  ·  (b) 2560  ·  (c) the 9th term
Exam tip Before reaching for differences, glance at the terms. If they double, triple or halve, the sequence is geometric. If they sit close to the square numbers 1, 4, 9, 16 or the cubes 1, 8, 27, 64, compare directly — 2, 5, 10, 17 is simply n² + 1.

Practice Now you try

Do every question on paper first, then open the solution and mark your own working.

Practice 1Find the nth term of 9, 13, 17, 21, … and the 50th term.
1
d = 4, a = 9  →  Tn = 4n + (9 − 4) = 4n + 5
2
T50 = 4(50) + 5 = 205
Tn = 4n + 5   ·   T50 = 205
Practice 2A sequence begins 100, 93, 86, 79, … Find the nth term and show whether 2 is a term.
1
d = −7, a = 100  →  Tn = 107 − 7n
2
Set the rule equal to 2. 107 − 7n = 2  →  7n = 105  →  n = 15 A positive integer, so 2 is a term.
Tn = 107 − 7n;   yes — 2 is the 15th term
Practice 3Find the nth term of 4, 7, 12, 19, 28, …
1
1st differences: 3, 5, 7, 9  ·  2nd: 2, 2, 2  →  a = 1
2
Subtract n². 4−1, 7−4, 12−9, 19−16, 28−25 = 3, 3, 3, 3, 3
Tn = n² + 3
Practice 4Find the nth term of 0, 7, 18, 33, 52, …
1
1st differences: 7, 11, 15, 19  ·  2nd: 4, 4, 4  →  a = 2
2
Subtract 2n². 0−2, 7−8, 18−18, 33−32, 52−50 = −2, −1, 0, 1, 2
3
The leftover has d = 1, first term −2, so it is n − 3. Tn = 2n² + n − 3    (check n = 1: 2 + 1 − 3 = 0 ✓)
Tn = 2n² + n − 3
Practice 5In a sequence, each term after the second is the sum of the two before it. The first term is 1 and the fourth term is 11. Find the second term.
1
Let the second term be x and build the sequence in terms of x. 1,  x,  1 + x,  1 + 2x
2
The fourth term is 11. 1 + 2x = 11  →  x = 5
Second term = 5   (sequence 1, 5, 6, 11, …)

Common mistakes Lose no easy marks

Giving a term-to-term rule as the nth term “Add 4 each time” scores nothing when the question says “find the nth term”. The answer must be a formula in n.
Forgetting to halve the second difference For a quadratic sequence the coefficient of n² is the second difference divided by 2, not the second difference itself.
Using r n instead of r n−1 For 5, 10, 20, … writing 5 × 2n gives 10 as the first term. The power must be n − 1.
Exam tip Always substitute n = 1 and one later value back into your rule before writing the final answer. Ten seconds of checking catches almost every slip in this topic.

Exit check Prove it before you leave

Exit 1Write down the nth term of 2, 4, 6, 8, …
Tn = 2n
Exit 2Is 50 a term of the sequence with nth term 3n + 2?
3n + 2 = 50 gives n = 16, a positive integer — yes, the 16th term.
Exit 3A quadratic sequence has second difference 6. What is the coefficient of n²?
6 ÷ 2 = 3
