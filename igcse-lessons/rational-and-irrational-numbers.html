Rational and Irrational Numbers

What makes a number rational, how to prove it, which roots are irrational, and what happens when you add or multiply the two kinds together.

1 ·  Rational or irrational?

Every real number is either rational or irrational — there is no third option and no overlap. The whole topic rests on one definition, so learn it word for word.

Definition A number is rational if it can be written as ab where a and b are integers and b ≠ 0. A number that cannot be written this way is irrational. The definition does not say the number must look like a fraction — only that it could be written as one. That is why 7, −3, 0.25 and 0.3̇ are all rational.

2 ·  Proving a recurring decimal is rational

To prove a recurring decimal is rational you must produce the fraction. The standard method is worth two or three marks, so show every line.

Example 2Show that 0.5̇4̇ is a rational number.
1
Call the number x and write out enough digits to see the pattern. x = 0.545454…
2
The repeating block has two digits, so multiply by 10² = 100. 100x = 54.545454…
3
Subtract — the infinite tails are identical and cancel exactly. 100x − x = 54.5454… − 0.5454…
99x = 54
4
Solve and cancel by 9. x = 54/99 = 6/11
5
State the conclusion in the language of the definition: 6 and 11 are integers with 11 ≠ 0, so x is rational.
0.5̇4̇ = 611, so it is rational
Exam tip Multiply by 10k where k is the length of the recurring block. If some digits do not recur, multiply twice (by 10 and by 10k+1) so the tails line up before subtracting.

3 ·  Combining the two kinds

Examiners love questions such as “is p + q rational or irrational?” Learn which combinations are guaranteed and which depend on the numbers.

CombinationResultExample

irrational + irrationaleither√2 + √2 = 2√2 (irrational) but √2 + (1 − √2) = 1 (rational)
non-zero rational × irrationalalways irrational5√3,  π/4

Why rational + irrational must be irrational

Let r be rational and x irrational, and suppose the sum r + x were rational, equal to s say. Then x = s − r. But the difference of two rationals is rational (a common denominator makes it one fraction of integers), so x would be rational — which it is not. The supposition fails, so r + x is irrational.

Example 3Let p = 3 + √5 and q = 3 − √5. Show that p + q and pq are both rational, but p and 2p are not.
1
Add. The surd parts cancel. p + q = (3 + √5) + (3 − √5) = 6
2
Multiply. This is a difference of two squares, (a + b)(a − b) = a² − b². pq = 3² − (√5)² = 9 − 5 = 4
3
Both results are integers, so both are rational.
4
p itself is rational + irrational, so it is irrational; and 2p = 6 + 2√5 still contains a non-zero multiple of √5, so it is irrational too. p = 5.2360…   2p = 10.4721… (never repeat)
p + q = 6 and pq = 4 are rational; p and 2p are irrational
Note A pair like 3 + √5 and 3 − √5 is called a pair of conjugates. Their sum and product are always rational — the fact that makes rationalising denominators work in the surds lesson.

4 ·  Finding a number in a given interval

“Write down an irrational number between 4 and 5” is worth one easy mark, provided you know the two standard tricks.

A rational number in an interval

Take the midpoint, or any convenient decimal that sits inside. Between 4 and 5: 4.5, or 9/2. Between √2 = 1.414… and √3 = 1.732…: 1.5. Always check both inequalities before writing it down.

An irrational number in an interval

Method 1 — square the ends. Between 4 and 5, square to get 16 and 25. Any integer strictly between them that is not a perfect square gives an irrational root: √17, √18, …, √24.

Method 2 — build a decimal. Write a decimal inside the interval whose digits follow a non-repeating pattern, e.g. 4.1010010001… Say in words that the pattern never repeats.

Example 4Write down (a) a rational and (b) an irrational number between 4 and 5, and (c) an irrational number between 2.1 and 2.2.
1
(a) Any terminating decimal or fraction in range. 4.5   (= 9/2, a fraction of integers)
2
(b) Square the bounds: 4² = 16 and 5² = 25. Choose a non-square between them. √17 = 4.1231…    4 < √17 < 5 ✓
3
(c) Squaring gives 4.41 and 4.84 — no useful integer between them, so build a decimal instead. 2.1010010001… The blocks of zeros grow by one each time, so the digits never settle into a repeating block.
(a) 4.5   (b) √17   (c) 2.1010010001…
Exam tip For part (c) you must say that the pattern never repeats. Writing the digits alone does not show the examiner that you understand why it is irrational.

99x = 42

1
One digit does not recur, so multiply twice so the tails line up. x = 0.8333…

1
Add and subtract — watch which parts cancel. p + q = 4    p − q = 2√3

Multiply using the difference of two squares. pq = 2² − (√3)² = 4 − 3 = 1

Common mistakes Lose no easy marks

Treating 22/7 as irrational Any fraction of two integers is rational — including 22/7. It is only an approximation to π, which is irrational. Closeness to an irrational number proves nothing.
Squaring a bracket term by term (1 + √2)² is not 1 + 2. Expand properly: (1 + √2)² = 1 + 2√2 + 2 = 3 + 2√2, which is irrational.
Assuming irrational × irrational is irrational It can go either way: √2 × √8 = √16 = 4 is rational, while √2 × √3 = √6 is not. Always test with the actual numbers.
Exam tip Your calculator only shows about ten digits, so it can never prove a number is irrational. Use it as a hint, then justify with algebra — produce the fraction, or name the non-square under the root.
