Question 1  [2 marks]
(a)Write down the next two terms of the sequence.
  1. The terms go up by the same amount each time: 11 − 7 = 4, 15 − 11 = 4, 19 − 15 = 4. — the sequence is linear
  2. 19 + 4 = 23 and 23 + 4 = 27, so the next two terms are 23 and 27
(b)Find an expression, in terms of n, for the nth term of this sequence.
  1. The common difference is 4, so the rule starts with 4n. — the coefficient of n is the common difference
  2. 4n gives 4, 8, 12, 16 … and each term of the sequence is 3 more.
  3. nth term = 4n + 3
  4. Check: n = 4 gives 4 × 4 + 3 = 19 ✓

Question 2  [3 marks]
(a)Write down the first three terms of the sequence.
  1. Substitute n = 1, 2 and 3 into 5n − 2.
  2. 5(1) − 2 = 3,  5(2) − 2 = 8,  5(3) − 2 = 13
  3. First three terms: 3, 8, 13
(b)Work out the 20th term.
  1. Substitute n = 20.
  2. 5 × 20 − 2 = 100 − 2 = 98
(c)One term of the sequence is 198.
Find the position of this term.
  1. Set the nth term equal to 198.
  2. 5n − 2 = 198
  3. 5n = 200 — add 2 to both sides
  4. n = 40 — divide both sides by 5
  5. Check: 5 × 40 − 2 = 198 ✓

Question 3  [3 marks]
(a)3   6   12   24   …
  1. Each term is double the one before: 6 ÷ 3 = 2, 12 ÷ 6 = 2, 24 ÷ 12 = 2. — a geometric sequence with common ratio 2
  2. 24 × 2 = 48
(b)1   4   9   16   …
  1. The terms are 12, 22, 32, 42. — the square numbers
  2. The next term is 52 = 25

  1. The differences are 1, 2, 3, 4, so they increase by 1 each time.

Question 4  [4 marks]
(a)Find an expression, in terms of n, for the nth term of this sequence.
  1. The common difference is 27 − 31 = −4. — the sequence goes down by 4 each time
  2. So the rule is −4n + k for some number k.
  3. When n = 1: −4 + k = 31, so k = 35.
  4. nth term = 35 − 4n
  5. Check: n = 3 gives 35 − 12 = 23 ✓
(b)Find the value of the first term of the sequence that is negative.
  1. A negative term needs 35 − 4n < 0.
  2. 35 < 4n, so n > 8.75 — divide both sides by 4
  3. n must be a whole number, so the first negative term is the 9th.
  4. 35 − 4 × 9 = 35 − 36 = −1
  5. Check: the 8th term is 35 − 32 = 3, which is still positive ✓

Question 5  [4 marks]
(a)Write down the next term of the sequence.
  1. The first differences are 5, 7, 9, 11, so the next difference is 13.
  2. 35 + 13 = 48
(b)Find an expression, in terms of n, for the nth term of this sequence.
  1. First differences: 5, 7, 9, 11.  Second differences: 2, 2, 2. — constant second difference, so the sequence is quadratic
  2. The n2 coefficient is 2 ÷ 2 = 1, so start with n2. — half the second difference
  3. Subtract n2 = 1, 4, 9, 16, 25 from the sequence: 2, 4, 6, 8, 10.
  4. That linear sequence has nth term 2n.
  5. nth term = n2 + 2n
  6. Check: n = 5 gives 25 + 10 = 35 ✓

Question 7  [4 marks]
(a)Work out the number of sticks in Pattern 4.
  1. Each new square adds 3 more sticks: 4, 7, 10, …
  2. Pattern 4 uses 10 + 3 = 13 sticks
(b)Find an expression, in terms of n, for the number of sticks in Pattern n.
  1. The numbers of sticks form a linear sequence with common difference 3.
  2. So the rule is 3n + k; when n = 1, 3 + k = 4, so k = 1.
  3. Number of sticks = 3n + 1
  4. Check: Pattern 3 gives 3 × 3 + 1 = 10 ✓
(c)One pattern in this sequence uses 100 sticks.
Find the pattern number.
  1. Solve 3n + 1 = 100.
  2. 3n = 99 — subtract 1 from both sides
  3. n = 33 — divide both sides by 3
  4. Check: 3 × 33 + 1 = 100 ✓

  1. Substitute n = 20 into 2n2 + n + 2.
  2. 2 × 400 + 20 + 2 = 800 + 22 = 822

Question 10  [6 marks]
(a)Find an expression, in terms of n, for the nth term of sequence A.
  1. First differences: 6, 8, 10, 12.  Second differences: 2, 2, 2. — constant second difference, so sequence A is quadratic
  2. Coefficient of n2 = 2 ÷ 2 = 1.
  3. Subtract n2 = 1, 4, 9, 16, 25: 7, 10, 13, 16, 19.
  4. That is linear with common difference 3 and nth term 3n + 4.
  5. nth term of A = n2 + 3n + 4
  6. Check: n = 5 gives 25 + 15 + 4 = 44 ✓
(b)Show that 158 is a term of sequence A and write down its position in the sequence.
  1. Solve n2 + 3n + 4 = 158.
  2. n2 + 3n − 154 = 0 — subtract 158 from both sides
  3. (n − 11)(n + 14) = 0 — factorise: −154 = −11 × 14 and −11 + 14 = 3
  4. n = 11 or n = −14; a position must be a positive integer.
  5. So 158 is the 11th term.
  6. Check: 112 + 3 × 11 + 4 = 121 + 33 + 4 = 158 ✓
(c)Find the first term of sequence B that is greater than 10 000.
  1. Sequence B is 5, 15, 45, 135, 405, 1215, 3645, 10935, …
  2. The 7th term is 5 × 36 = 3645, which is too small.
  3. The 8th term is 5 × 37 = 10 935 — the first term over 10 000
