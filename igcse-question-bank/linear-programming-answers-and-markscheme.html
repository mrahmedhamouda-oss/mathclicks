  4. The greatest number of sponge cakes is 24
  5. Check: 400 × 10 + 250 × 24 = 4000 + 6000 = 10 000 g = 10 kg exactly ✓

Question 25  [6 marks]
(a)Find the equation of L.
  1. Gradient = 7 − 1⁄3 − 0 = 2
  2. The line crosses the y-axis at (0, 1), so c = 1.
  3. y = 2x + 1
  4. Check: (3, 7) gives 2 × 3 + 1 = 7 ✓
(b)Write down the three inequalities that define R.
  1. R is below L, and L is broken, so the inequality is strict: y < 2x + 1 — test (2, 4): 4 < 5 ✓
  2. The other two boundaries are solid: y ≥ 1 and x + y ≤ 7
  3. y < 2x + 1, y ≥ 1, x + y ≤ 7
(c)Find the number of points in R that have integer coordinates.
  1. Count column by column. Points on L are excluded; points on the other two lines are included.
  2. x = 0: need y < 1 and y ≥ 1 — none.
  3. x = 1: y < 3, so y = 1, 2 (2 points) — (1, 3) is on the broken line
  4. x = 2: y < 5 and y ≤ 5, so y = 1, 2, 3, 4 (4 points)
  5. x = 3: y ≤ 4 (4 points)
  6. x = 4: y ≤ 3 (3 points); x = 5: 2 points; x = 6: 1 point
  7. Total = 2 + 4 + 4 + 3 + 2 + 1 = 16
