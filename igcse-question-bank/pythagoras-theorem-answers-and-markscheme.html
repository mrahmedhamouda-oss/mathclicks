Question 9  [5 marks]

  3. x2 + x2 + 14x + 49 = x2 + 16x + 64 — expand both squared brackets
  4. 2x2 + 14x + 49 = x2 + 16x + 64 — collect the left-hand side
  5. x2 − 2x − 15 = 0 — subtract x2 + 16x + 64 from both sides

  4. Check: 52 + 122 = 25 + 144 = 169 = 132 ✓
