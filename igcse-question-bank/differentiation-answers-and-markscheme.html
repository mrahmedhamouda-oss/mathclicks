Question 4  [4 marks]

  2. −9x → −9   5 → 0
  3. dy⁄dx = 3x2 − 6x − 9
(b)Find the two values of x for which the curve has a stationary point.
  1. At a stationary point the gradient is zero, so dy⁄dx = 0. — the tangent to the curve is horizontal there
  2. 3x2 − 6x − 9 = 0

Question 6  [4 marks]
(a)Show that dy⁄dx = 4x + 7.
  1. Expand the brackets first — the product rule is not needed.
  2. y = (2x − 3)(x + 5) = 2x2 + 10x − 3x − 15
  3. y = 2x2 + 7x − 15 — collecting like terms
  4. Differentiate: dy⁄dx = 4x + 7 as required
(b)Find the coordinates of the stationary point of the curve.
  1. At the stationary point, 4x + 7 = 0. — the gradient is zero
  2. 4x = −7, so x = −7⁄4 = −1.75
  3. y = 2(−1.75)2 + 7(−1.75) − 15 = 6.125 − 12.25 − 15
  4. Stationary point = (−1.75, −21.125)
  5. Check with the factorised form: (2 × −1.75 − 3)(−1.75 + 5) = (−6.5)(3.25) = −21.125 ✓

Question 9  [5 marks]
(a)Show that A = x2 + 128⁄x.
  1. Volume = x2h = 32, so h = 32⁄x2. — the base is a square of side x
  2. The tank is open, so the surface is one square base and four rectangular sides. — there is no lid
  3. A = x2 + 4xh
  4. A = x2 + 4x × 32⁄x2 = x2 + 128x⁄x2
  5. A = x2 + 128⁄x as required
(b)Find dA⁄dx.
  1. Write A = x2 + 128x−1.
  2. dA⁄dx = 2x − 128⁄x2
(c)Work out the value of x that makes A a minimum, and find this minimum surface area.
  1. For a minimum, dA⁄dx = 0.
  2. 2x = 128⁄x2, so 2x3 = 128 — multiplying both sides by x2
  3. x3 = 64, so x = 4 — the cube root of 64 is 4
  4. A = 42 + 128⁄4 = 16 + 32 = 48 m2
  5. Check: h = 32⁄16 = 2 m, and 16 + 4 × 4 × 2 = 48 ✓

Question 10  [6 marks]
(a)Find dy⁄dx.
  1. x3 → 3x2   3x2 → 6x
  2. −9x → −9   −2 → 0
  3. dy⁄dx = 3x2 + 6x − 9
(b)Find the coordinates of the two stationary points on the curve.
  1. Set the derivative to zero: 3x2 + 6x − 9 = 0
  2. Divide by 3: x2 + 2x − 3 = 0
  3. (x + 3)(x − 1) = 0, so x = −3 or x = 1 — 3 × (−1) = −3 and 3 + (−1) = 2
  4. When x = 1: y = 1 + 3 − 9 − 2 = −7
  5. When x = −3: y = −27 + 27 + 27 − 2 = 25
  6. Stationary points are (1, −7) and (−3, 25)
(c)Determine whether each stationary point is a maximum or a minimum. Give a reason for each answer.
  1. Differentiate again: d2y⁄dx2 = 6x + 6 — the second derivative tests the nature of a stationary point
  2. At x = 1: 6 × 1 + 6 = 12, which is positive.
  3. So (1, −7) is a minimum — the second derivative is positive, so the curve is bending upwards
  4. At x = −3: 6 × (−3) + 6 = −12, which is negative.
  5. So (−3, 25) is a maximum — the second derivative is negative, so the curve is bending downwards
