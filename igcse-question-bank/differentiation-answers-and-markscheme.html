Question 10  [6 marks]
(a)Find dy⁄dx.
  1. x3 → 3x2   3x2 → 6x
  2. −9x → −9   −2 → 0
  3. dy⁄dx = 3x2 + 6x − 9
(b)Find the coordinates of the two stationary points on the curve.
  1. Set the derivative to zero: 3x2 + 6x − 9 = 0
  2. Divide by 3: x2 + 2x − 3 = 0
  3. (x + 3)(x − 1) = 0, so x = −3 or x = 1 — 3 × (−1) = −3 and 3 + (−1) = 2
  4. When x = 1: y = 1 + 3 − 9 − 2 = −7
  5. When x = −3: y = −27 + 27 + 27 − 2 = 25
  6. Stationary points are (1, −7) and (−3, 25)
(c)Determine whether each stationary point is a maximum or a minimum. Give a reason for each answer.
  1. Differentiate again: d2y⁄dx2 = 6x + 6 — the second derivative tests the nature of a stationary point
  2. At x = 1: 6 × 1 + 6 = 12, which is positive.
  3. So (1, −7) is a minimum — the second derivative is positive, so the curve is bending upwards
  4. At x = −3: 6 × (−3) + 6 = −12, which is negative.
  5. So (−3, 25) is a maximum — the second derivative is negative, so the curve is bending downwards
