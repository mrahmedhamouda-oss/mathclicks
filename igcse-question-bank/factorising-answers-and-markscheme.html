Question 1  [2 marks]
(a)Factorise 7x + 21.
  1. Look for the highest common factor of 7x and 21. — 7 divides both terms; there is no common letter
  2. 7x + 21 = 7(x + 3) — take out the common factor 7
  3. Check by expanding: 7 × x + 7 × 3 = 7x + 21 ✓
(b)Factorise 10y2 − 4y.
  1. The HCF of 10y2 and 4y is 2y. — 2 is the HCF of 10 and 4; y is the highest power of y in both terms
  2. 10y2 − 4y = 2y(5y − 2)
  3. Check: 2y × 5y − 2y × 2 = 10y2 − 4y ✓

Question 4  [4 marks]
(a)Factorise 3x + 3y + ax + ay.
  1. Group the four terms in pairs: (3x + 3y) + (ax + ay). — the first pair has a common factor 3, the second has a common factor a
  2. = 3(x + y) + a(x + y) — factorise each pair
  3. Both terms now contain the bracket (x + y).
  4. 3x + 3y + ax + ay = (3 + a)(x + y) — take out the common bracket
  5. Check: 3x + 3y + ax + ay ✓ — expanding gives back all four terms
(b)Factorise completely 2m2 − 50.
  1. Take out the common factor 2 first. — “completely” means the numerical factor must come out too
  2. 2m2 − 50 = 2(m2 − 25)
  3. m2 − 25 = (m + 5)(m − 5) — difference of two squares
  4. 2m2 − 50 = 2(m + 5)(m − 5)

Question 8  [4 marks]

(a)Simplify (2x2 + 7x + 3)⁄(x2 − 9), giving your answer in its simplest form.
  1. Numerator: 2 × 3 = 6 and 6 + 1 = 7, so split 7x as 6x + x. — the “ac” method
  2. 2x2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)
  3. Denominator: x2 − 9 = (x + 3)(x − 3) — difference of two squares
  4. (2x + 1)(x + 3)⁄(x + 3)(x − 3) = (2x + 1)⁄(x − 3) — cancel the common factor (x + 3)
(b)Hence solve (2x2 + 7x + 3)⁄(x2 − 9) = 3.
  1. Using the simplified form: (2x + 1)⁄(x − 3) = 3
  2. 2x + 1 = 3(x − 3) = 3x − 9 — multiply both sides by (x − 3)
  3. x = 10 — subtract 2x and add 9
  4. Check in the original: (200 + 70 + 3)⁄(100 − 9) = 273⁄91 = 3 ✓
(c)Write down the positive value of x for which the simplified expression is not defined.
  1. A fraction is not defined when its denominator is zero: x − 3 = 0.
  2. x = 3 — the original expression is also undefined at x = −3
