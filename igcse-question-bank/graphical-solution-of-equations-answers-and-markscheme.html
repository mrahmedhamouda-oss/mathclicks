Question 1  [2 marks]
Use the graph to solve the equation x² − 2x − 3 = 0.
  1. Solving x² − 2x − 3 = 0 means finding where y = 0. — the equation is the curve set equal to zero
  2. Read off where the curve crosses the x-axis.
  3. x = −1 and x = 3
  4. Check: (−1)² − 2(−1) − 3 = 0 and 3² − 2(3) − 3 = 0 ✓ — both readings satisfy the equation

Question 2  [3 marks]
(a)Use the graph to solve the equation x² + x − 4 = 0.
Give your answers correct to 1 decimal place.
  1. The equation is y = 0, so read where the curve crosses the x-axis.
  2. The curve crosses between −3 and −2, and between 1 and 2.
  3. x = −2.6 and x = 1.6 (1 d.p.) — exact values (−1 ± √17)⁄2 = −2.5615… and 1.5615…
(b)Write down the equation of the line of symmetry of the graph.
  1. A parabola is symmetrical about the vertical line through its lowest point.
  2. The lowest point is halfway between the two roots: (−2.5615 + 1.5615)⁄2 = −0.5
  3. Line of symmetry: x = −0.5 — it is a vertical line, so its equation starts ‘x =’

Question 5  [4 marks]
(a)Show that the equation 6⁄x = x + 1 can be written as x² + x − 6 = 0.
  1. 6⁄x = x + 1
  2. 6 = x(x + 1) — multiply both sides by x (x ≠ 0)
  3. 6 = x² + x — expand the bracket
  4. x² + x − 6 = 0 — subtract 6 from both sides, as required
(b)On the grid, draw the line y = x + 1 and use it to solve 6⁄x = x + 1.
  1. y = x + 1 is a straight line through (0, 1) with gradient 1; it passes through (−4, −3) and (5, 6). — plot two points and join them with a ruler
  2. The line crosses the curve twice.
  3. x = −3 and x = 2
  4. Check by factorising: x² + x − 6 = (x + 3)(x − 2) = 0 ✓

Question 9  [5 marks]
(a)Find the equation of the straight line that must be drawn on the grid to solve the equation x³ − 3x − 2 = 0.
  1. The curve is y = x³ − 5x + 1 and the line is y = mx + c.
  2. At an intersection x³ − 5x + 1 = mx + c, and this must become x³ − 3x − 2 = 0.
  3. Subtract: (x³ − 5x + 1) − (x³ − 3x − 2) = −2x + 3
  4. Line to draw: y = 3 − 2x
(b)Draw this line and use it to solve x³ − 3x − 2 = 0.
  1. Draw y = 3 − 2x through (0, 3) and (2, −1).
  2. It touches the curve at x = −1 and crosses it at x = 2.
  3. x = −1 and x = 2
  4. Check: x³ − 3x − 2 = (x + 1)²(x − 2) ✓
(c)Give a reason why this equation has only two different solutions.
  1. A cubic can meet a line three times, but here the line only touches at x = −1.
  2. The line is a tangent to the curve at x = −1, so that solution is repeated. — the factorised form (x + 1)²(x − 2) = 0 shows the repeated root

Question 10  [6 marks]
(a)Write down the coordinates of the local maximum point of the curve.
  1. The local maximum is the top of the first bend in the curve.
  2. It occurs at x = 1, where y = 1 − 6 + 9 = 4.
  3. Local maximum = (1, 4)
(b)Use the graph to solve the equation x³ − 6x² + 9x = 2.
Give your answers correct to 1 decimal place.
  1. Draw the horizontal line y = 2 across the grid.
  2. It cuts the curve three times: on the rising part, on the falling part and on the final rising part.
  3. x = 0.3, x = 2 and x = 3.7 (1 d.p.) — exact values 2 − √3, 2 and 2 + √3
  4. Check: 2³ − 6(2²) + 9(2) = 8 − 24 + 18 = 2 ✓
(c)Find the values of k for which the equation x³ − 6x² + 9x = k has three different solutions.
  1. y = k is a horizontal line; it must cut the curve three times.
  2. The local minimum is (3, 0) and the local maximum is (1, 4).
  3. If k = 0 or k = 4 the line only touches at a turning point, so there are only two different solutions.
  4. 0 < k < 4 — strict inequalities
