Question 9  [5 marks]
(a)Show that 91/2 × 272/3 ÷ 3−1 = 81.
  1. Write every term as a power of 3.
  2. 91/2 = (32)1/2 = 31
  3. 272/3 = (33)2/3 = 32
  4. 31 × 32 ÷ 3−1 = 31+2−(−1) = 34 — add for ×, subtract for ÷
  5. 34 = 81, as required
(b)Solve 42x − 1 = 8x + 2.
  1. Write both sides as powers of 2: 4 = 22 and 8 = 23.
  2. 42x−1 = (22)2x−1 = 24x−2 — multiply the indices
  3. 8x+2 = (23)x+2 = 23x+6 — multiply the indices
  4. 4x − 2 = 3x + 6 — the bases are equal, so the indices are equal
  5. x = 8
  6. Check: 415 = 1 073 741 824 and 810 = 1 073 741 824 ✓

Question 10  [6 marks]
(a)Simplify (25x6y−4)1/2, giving your answer with positive indices only.
  1. Apply the index 1⁄2 to each factor.
  2. 251/2 = 5, (x6)1/2 = x3, (y−4)1/2 = y−2 — multiply the indices
  3. y−2 = 1 ⁄ y2 — a negative index gives the reciprocal
  4. (25x6y−4)1/2 = 5x3 ⁄ y2
(b)Use the information above to write down two equations in a and b.
  1. 2a × 2b = 2a+b and 32 = 25. — multiplying: add the indices
  2. 2a ÷ 2b = 2a−b and 2 = 21. — dividing: subtract the indices
  3. Equating indices gives a + b = 5 and a − b = 1
(c)Find the value of a.
  1. Add the two equations: (a + b) + (a − b) = 5 + 1 — eliminate b
  2. 2a = 6, so a = 3
(d)Write down the value of b.
  1. Substitute a = 3 into a + b = 5.
  2. b = 2
  3. Check: 23 × 22 = 8 × 4 = 32 ✓ and 23 ÷ 22 = 8 ÷ 4 = 2 ✓
