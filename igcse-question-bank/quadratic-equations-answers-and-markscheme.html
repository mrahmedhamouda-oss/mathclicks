Question 1  [2 marks]
(a)(x − 4)(x + 9) = 0
  1. A product is zero only when one of the factors is zero. — the zero-product rule
  2. x − 4 = 0 gives x = 4, and x + 9 = 0 gives x = −9.
  3. x = 4 or x = −9
(b)x(x − 6) = 0
  1. The two factors are x and (x − 6).
  2. x = 0, or x − 6 = 0 giving x = 6.
  3. x = 0 or x = 6 — do not lose the root x = 0 by dividing by x

Question 2  [3 marks]
(a)x2 + 3x − 28 = 0

  2. +7 × −4 = −28 and +7 + (−4) = +3

  4. x = −7 or x = 4

  2. x = 9 or x = −9

Question 3  [3 marks]
Solve 2x2 − 7x + 3 = 0.
  1. Multiply the outer coefficients: 2 × 3 = 6.
  2. Two numbers with product 6 and sum −7 are −1 and −6.
  3. 2x2 − x − 6x + 3 = 0 — split the middle term
  4. x(2x − 1) − 3(2x − 1) = 0, so (2x − 1)(x − 3) = 0 — factorise in pairs
  5. x = 1⁄2 or x = 3
  6. Check: 2(1⁄2)2 − 7(1⁄2) + 3 = 0.5 − 3.5 + 3 = 0 ✓

Question 4  [4 marks]
Solve x2 − 5x − 3 = 0.
  1. This does not factorise, so use the quadratic formula with a = 1, b = −5 and c = −3.
  2. x = [ −b ± √(b2 − 4ac) ] ÷ 2a
  3. b2 − 4ac = (−5)2 − 4 × 1 × (−3) = 25 + 12 = 37 — take care with the double negative
  4. x = (5 ± √37) ÷ 2 and √37 = 6.0827…
  5. x = (5 + 6.0827) ÷ 2 = 5.5413… or x = (5 − 6.0827) ÷ 2 = −0.5413…
  6. x = 5.54 or x = −0.54 (2 d.p.)
  7. Check: 5.54 + (−0.54) = 5 = −b⁄a ✓ — the sum of the roots

Question 5  [4 marks]
(a)Write x2 + 8x + 3 in the form (x + a)2 + b.
  1. Halve the coefficient of x: 8 ÷ 2 = 4, so start with (x + 4)2.
  2. (x + 4)2 = x2 + 8x + 16, which is 13 too big. — expand to compare
  3. x2 + 8x + 3 = (x + 4)2 − 13
(b)Hence solve x2 + 8x + 3 = 0, giving your answers correct to 3 significant figures.
  1. (x + 4)2 − 13 = 0, so (x + 4)2 = 13
  2. x + 4 = ±√13 = ±3.6055… — remember both square roots
  3. x = −4 + 3.6055 = −0.3944… or x = −4 − 3.6055 = −7.6055…
  4. x = −0.394 or x = −7.61 (3 s.f.)

Question 6  [4 marks]
(a)Show that x2 + 3x − 40 = 0.
  1. Area of a rectangle = length × width
  2. x(x + 3) = 40 — using the area given
  3. x2 + 3x = 40 — expand the bracket
  4. x2 + 3x − 40 = 0 — subtract 40 from both sides
(b)Solve the equation and work out the perimeter of the rectangle.
  1. Two numbers with product −40 and sum +3 are +8 and −5.
  2. (x + 8)(x − 5) = 0, so x = −8 or x = 5.
  3. A width cannot be negative, so x = 5 and the rectangle is 5 cm by 8 cm.
  4. Perimeter = 2 × (5 + 8) = 26 cm
  5. Check: 5 × 8 = 40 cm2 ✓

Question 7  [4 marks]
(a)Factorise 6x2 − 11x − 10.
  1. Multiply the outer coefficients: 6 × (−10) = −60.
  2. Two numbers with product −60 and sum −11 are +4 and −15.
  3. 6x2 + 4x − 15x − 10 — split the middle term
  4. 2x(3x + 2) − 5(3x + 2) = (3x + 2)(2x − 5) — factorise in pairs

  3. 2x − 5 = 0 gives x = 5⁄2
  4. x = −2⁄3 or x = 2.5

Question 8  [4 marks]
(a)Show that n2 + 2n − 195 = 0.
  1. The product of the two numbers is 195.
  2. n(n + 2) = 195
  3. n2 + 2n = 195 — expand the bracket
  4. n2 + 2n − 195 = 0 — subtract 195 from both sides
(b)Solve the equation and write down the two numbers.
  1. Two numbers with product −195 and sum +2 are +15 and −13.
  2. (n + 15)(n − 13) = 0, so n = −15 or n = 13.
  3. The numbers are positive, so n = 13. — reject n = −15
  4. The two numbers are 13 and 15
  5. Check: 13 × 15 = 195 ✓

Question 9  [5 marks]
(a)Show that x2 + 10x − 1200 = 0.
  1. Time = distance ÷ speed, so the outward journey takes 120⁄x hours and the return journey 120⁄(x + 10) hours.
  2. 120⁄x − 120⁄(x + 10) = 1 — the return journey is 1 hour shorter
  3. 120(x + 10) − 120x = x(x + 10) — multiply every term by x(x + 10)
  4. 120x + 1200 − 120x = x2 + 10x, so 1200 = x2 + 10x
  5. x2 + 10x − 1200 = 0
(b)Solve the equation to find her average speed on the outward journey.
  1. Two numbers with product −1200 and sum +10 are +40 and −30.
  2. (x + 40)(x − 30) = 0, so x = −40 or x = 30.
  3. A speed cannot be negative, so x = 30 km/h
  4. Check: 120 ÷ 30 = 4 hours and 120 ÷ 40 = 3 hours, a difference of 1 hour ✓

Question 10  [6 marks]
(a)Write 2x2 − 12x + 5 in the form a(x + b)2 + c.
  1. Take the factor 2 out of the first two terms: 2(x2 − 6x) + 5
  2. x2 − 6x = (x − 3)2 − 9 — half of −6 is −3, and (x − 3)2 gives an extra +9
  3. 2[(x − 3)2 − 9] + 5 = 2(x − 3)2 − 18 + 5
  4. 2x2 − 12x + 5 = 2(x − 3)2 − 13
(b)Write down the coordinates of the turning point of the graph of y = 2x2 − 12x + 5.
  1. (x − 3)2 is never negative and is 0 when x = 3.
  2. So the least value of y is −13, at x = 3.
  3. Turning point (3, −13) — a minimum, because the coefficient of x2 is positive
(c)Solve 2x2 − 12x + 5 = 0, giving your answers correct to 3 significant figures.
  1. 2(x − 3)2 − 13 = 0, so (x − 3)2 = 6.5
  2. x − 3 = ±√6.5 = ±2.5495…
  3. x = 3 + 2.5495 = 5.5495… or x = 3 − 2.5495 = 0.4504…
  4. x = 5.55 or x = 0.450 (3 s.f.)
  5. Check: 5.5495 + 0.4504 = 6 = −b⁄a ✓ — the sum of the roots
