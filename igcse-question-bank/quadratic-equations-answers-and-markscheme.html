Question 1  [2 marks]
(a)(x − 4)(x + 9) = 0
  1. A product is zero only when one of the factors is zero. — the zero-product rule
  2. x − 4 = 0 gives x = 4, and x + 9 = 0 gives x = −9.
  3. x = 4 or x = −9
(b)x(x − 6) = 0
  1. The two factors are x and (x − 6).
  2. x = 0, or x − 6 = 0 giving x = 6.
  3. x = 0 or x = 6 — do not lose the root x = 0 by dividing by x

Question 4  [4 marks]

  1. This does not factorise, so use the quadratic formula with a = 1, b = −5 and c = −3.
  2. x = [ −b ± √(b2 − 4ac) ] ÷ 2a
