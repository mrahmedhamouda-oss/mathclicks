Question 4  [4 marks]
(a)Find f−1(x).
  1. Write y = 3x − 8 and make x the subject. — the inverse undoes the function
  2. y + 8 = 3x — add 8 to both sides
  3. x = (y + 8)⁄3 — divide both sides by 3
  4. f−1(x) = (x + 8)⁄3 — rewrite in terms of x
(b)Find f−1(4).
  1. f−1(4) = (4 + 8)⁄3 = 12⁄3 — substitute x = 4 into the inverse
  2. = 4 — check: f(4) = 12 − 8 = 4 ✓
(c)Write down the value of ff−1(19).
  1. f−1 sends 19 to some number, then f sends it straight back.
  2. ff−1(19) = 19 — a function and its inverse undo each other, so ff−1(x) = x

Question 5  [4 marks]

  1. fg(x) means do g first, then f. — work from the inside out

  3. = 2x² + 6 − 1 — expand the bracket

  1. x² − 3 = 22 — set the function equal to 22

Question 10  [6 marks]
(a)Find f−1(x), giving your answer as a single fraction.
  1. Write y = (x + 1)⁄(x − 4) and make x the subject.
  2. y(x − 4) = x + 1 — multiply both sides by (x − 4)
  3. xy − 4y = x + 1 — expand the bracket
  4. xy − x = 4y + 1 — collect the terms containing x on one side
  5. x(y − 1) = 4y + 1 — factorise the left-hand side
  6. f−1(x) = (4x + 1)⁄(x − 1) — divide by (y − 1), then rewrite in terms of x
  7. Check: f(9) = 10⁄5 = 2 and f−1(2) = 9⁄1 = 9 ✓
(b)Solve f(x) = x.
Give your answers correct to 3 significant figures.
  1. (x + 1)⁄(x − 4) = x
  2. x + 1 = x(x − 4) — multiply both sides by (x − 4)
  3. x + 1 = x² − 4x — expand
  4. x² − 5x − 1 = 0 — collect everything on one side
  5. x = 5 ± √(25 + 4)⁄2 = (5 ± √29)⁄2 — quadratic formula with a = 1, b = −5, c = −1
  6. x = 5.19258… or x = −0.19258…
  7. x = 5.19 or x = −0.193 (3 s.f.) — exact values (5 ± √29)⁄2
