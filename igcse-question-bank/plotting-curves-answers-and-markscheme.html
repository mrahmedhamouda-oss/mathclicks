Question 4  [4 marks]
(a)Complete the table of values.
  1. When x = −1: y = (−1)³ − 4(−1) = −1 + 4 = 3 — a negative number cubed is negative
  2. When x = 2: y = 2³ − 4(2) = 8 − 8 = 0
  3. Missing values: 3 and 0
(b)On the grid, draw the graph of y = x³ − 4x for −3 ≤ x ≤ 3.
  1. Plot (−3, −15), (−2, 0), (−1, 3), (0, 0), (1, −3), (2, 0) and (3, 15).
  2. Join the points with a single smooth curve — not straight line segments.
  3. The curve rises to a local maximum near x = −1.15, falls to a local minimum near x = 1.15, then rises again, cutting the x-axis at −2, 0 and 2. — a cubic with a positive x³ term has this ‘rise–fall–rise’ shape

  3. Missing values: 7 and 1

Question 8  [4 marks]
(a)Write down the coordinates of the two points where the curve crosses the x-axis.
  1. The curve crosses the x-axis where y = 0.
  2. Reading from the graph, this happens at x = 1 and x = 3.
  3. Points: (1, 0) and (3, 0) — algebraically x² − 4x + 3 = (x − 1)(x − 3) = 0
(b)Write down the coordinates of the point where the curve crosses the y-axis.
  1. The curve crosses the y-axis where x = 0.
  2. y = 0 − 0 + 3 = 3, so the point is (0, 3) — the constant term of the equation is always the y-intercept
(c)Write down the minimum value of y.
  1. The lowest point of the curve is half way between x = 1 and x = 3, at x = 2.
  2. y = 2² − 4(2) + 3 = 4 − 8 + 3 = −1

  1. The highest point of the first bend is where the curve stops rising and starts falling.

Question 10  [6 marks]
(a)Find the value of a, the value of b and the value of c.
  1. At (0, 5): a(0)² + b(0) + c = 5, so c = 5 — substitute the coordinates of each point into the equation
  2. At (1, 2): a + b + 5 = 2, so a + b = −3
  3. At (−1, 10): a − b + 5 = 10, so a − b = 5
  4. Adding the two equations: 2a = 2, so a = 1 — eliminate b
  5. Then 1 + b = −3, so b = −4
  6. a = 1, b = −4, c = 5
  7. Check at (−1, 10): 1 + 4 + 5 = 10 ✓
(b)Write down the coordinates of the lowest point of the curve.
  1. The curve is y = x² − 4x + 5.
  2. Completing the square: y = (x − 2)² + 1 — (x − 2)² = x² − 4x + 4, and 4 + 1 = 5
  3. (x − 2)² is never negative and equals 0 when x = 2, so the least value of y is 1.
  4. Lowest point = (2, 1)
