Question 10  [6 marks]
(a)Find the value of a, the value of b and the value of c.
  1. At (0, 5): a(0)² + b(0) + c = 5, so c = 5 — substitute the coordinates of each point into the equation
  2. At (1, 2): a + b + 5 = 2, so a + b = −3
  3. At (−1, 10): a − b + 5 = 10, so a − b = 5
  4. Adding the two equations: 2a = 2, so a = 1 — eliminate b
  5. Then 1 + b = −3, so b = −4
  6. a = 1, b = −4, c = 5
  7. Check at (−1, 10): 1 + 4 + 5 = 10 ✓
(b)Write down the coordinates of the lowest point of the curve.
  1. The curve is y = x² − 4x + 5.
  2. Completing the square: y = (x − 2)² + 1 — (x − 2)² = x² − 4x + 4, and 4 + 1 = 5
  3. (x − 2)² is never negative and equals 0 when x = 2, so the least value of y is 1.
  4. Lowest point = (2, 1)

Question 12  [3 marks]
Write down the letter of the graph of each of these equations.
One of the graphs is not used.

y = x³   ………      y = 2x   ………      y = 1⁄x   ………
  1. y = x³ passes through the origin, is negative for negative x and positive for positive x, with an S-shaped bend: graph D. — a cubic with a positive x³ term
  2. y = 2x is always positive, passes through (0, 1) and flattens towards the x-axis on the left: graph C. — exponential growth, asymptote y = 0
  3. y = 1⁄x is in two separate parts and never touches either axis: graph A. — a reciprocal graph (hyperbola)
  4. Graph B is an ‘upside-down’ parabola such as y = 3 − x², and is not used.
