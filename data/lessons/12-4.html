Core Concepts

1. Probability is still just favorable ÷ possible

Nothing about probability changes in this lesson. The only new thing is how you count the two numbers. When the outcomes are arrangements or selections, you count them with factorials, permutations, or combinations.

P(event) = (number of favorable outcomes) / (number of possible outcomes)
Study Tip — Randomness: When outcomes are decided at random, they are equally likely to occur, so their probabilities can be calculated using permutations and combinations.

2. Vocabulary

Permutation — an arrangement of objects in which order is important. Shuffling 7 songs into the order Track 5, 7, 1, 2, 6, 4, 3 is one permutation of the playlist.
Factorial — the factorial of a positive integer n is the product of the positive integers less than or equal to n, written n!.
Combination — a selection of objects in which order is not important. Choosing 3 people for a committee is a combination.
Fundamental Counting Principle — if one stage has a outcomes and the next has b, the pair of stages has a × b outcomes. Everything below is built from this.
Key Concept · Factorial
Words: The factorial of a positive integer n is the product of the positive integers less than or equal to n, and is written n!.
Symbols: n! = n · (n − 1) · (n − 2) · … · 2 · 1,  where 0! = 1
1! = 1    2! = 2    3! = 6    4! = 24    5! = 120
6! = 720    7! = 5040    8! = 40,320    9! = 362,880
Watch Out! 0! = 1, not 0. It is defined that way so that the permutation and combination formulas keep working at the edges (for example nPn = n!/0! = n!).

3. The one decision that drives this whole lesson

Before you compute anything, ask a single question: if I swap two of the chosen objects, do I get a different outcome? If yes, order matters and you are counting permutations. If no, order does not matter and you are counting combinations.

Order MATTERS → permutation

• first, second, third place
• president, then vice‑president
• seat C11 vs seat C12
• a password / a phone number
• "in that order", "first from the left"

Order does NOT matter → combination

• a committee of 3
• 4 flavors on one cone
• which 6 people replied
• a set of 3 points
• "in any order", "a group of", "chosen"
Study Tip — Permutations and Combinations: Use permutations when the order of an arrangement is important, and use combinations when the order is not important.

4. Permutations of n objects taken r at a time

Line up 7 songs and play only 4 of them. By the Fundamental Counting Principle there are 7 · 6 · 5 · 4 = 840 playlists. The formula is just a compact way of writing that falling product: start at n and take r factors.

Key Concept · Permutations
Words: The number of permutations of n distinct objects taken r at a time is denoted by nPr and given by nPr = n! / (n − r)!.
Symbols: The number of permutations of 7 objects taken 4 at a time is 7P4 = 7!/(7 − 4)! = (7·6·5·4·3·2·1)/(3·2·1) = 840.
!
nPr is just r descending factors starting at n. 12P4 = 12·11·10·9 = 11,880. You almost never need to expand the whole factorial.

5. Combinations — and why nCr = nPr ÷ r!

A combination of n objects taken r at a time is calculated by dividing the number of permutations nPr by the number of arrangements containing the same elements, r!. Every group of r objects was counted r! times by nPr — once for each of its own orderings — so divide that duplication away.

Key Concept · Combinations
Symbols: The number of combinations of n distinct objects taken r at a time is denoted by nCr and given by nCr = n! / ((n − r)! · r!).
Example: 7C3 = 7!/((7−3)!·3!) = 7!/(4!·3!) = (7·6·5·4!)/(4!·6) = 35.

Same numbers, side by side. Take n = 7, r = 3.

Permutation — 7P3

7P3 = 7!/(7 − 3)!
= 7!/4!
= (7·6·5·4!)/4!
= 7·6·5
= 210 ordered triples

Combination — 7C3

7C3 = 7!/((7 − 3)!·3!)
= 7!/(4!·3!)
= (7·6·5)/(3·2·1)
= 210/6
= 35 unordered groups
7P3 ÷ 3! = 210 ÷ 6 = 35 = 7C3   ∴   r! · nCr = nPr

6. Permutations with repetition

If some of the objects are identical, swapping two identical objects does not create a new arrangement. So you take the n! arrangements you would get if everything were distinct, and divide by r1! for the first repeated object, r2! for the second, and so on.

Key Concept · Permutations with Repetition
The number of distinguishable permutations of n objects in which one object is repeated r1 times, another is repeated r2 times, and so on, is
n! / (r1! · r2! · … · rk!)
Digits 2, 2, 5, 5, 8 → n = 5, two 2s, two 5s, one 8
5! / (2! · 2! · 1!) = 120 / 4 = 30 distinguishable arrangements
Watch Out! Only divide by the factorial of counts that are 2 or more — but dividing by 1! is harmless since 1! = 1. The numerator is always n! where n is the total number of objects, not the number of distinct types.

7. The selection procedure — use this every time

Read for the order clue. Words like first, second, in that order, arranged, lined up, ranked mean order matters. Words like chosen, selected, a group of, in any order mean it does not.
Count the possible outcomes (the denominator). Order matters → nPr. Order does not → nCr. Identical objects present → n!/(r1!·r2!·…).
Count the favorable outcomes (the numerator) with the same kind of counting. If the specified objects may appear in any order among themselves, the numerator is r!; if their order is pinned down, it is 1.
Divide and simplify. Cancel factorials before multiplying — 30!/32! = 1/(32·31) is far easier than computing 32!.
Sanity-check. The answer must be between 0 and 1, and the denominator you used must be at least as large as the numerator.
2
Two shortcuts worth memorising: nCn−r = nCr (choosing which r to take is the same as choosing which n−r to leave), and nC0 = nCn = 1.
=
nPr = nCr is sometimes true — exactly when r! = 1, i.e. r = 0 or r = 1. For every r ≥ 2, nPr > nCr.
n
nPn = n!/0! = n! and nPn−1 = n!/1! = n! — they are equal. Arranging all n objects is the same as arranging n−1 of them, because the last object has no choice left.

Worked Examples

32 performers are assigned all 32 slots at random. What is the probability that a specified performer takes slot 1 and a second specified performer takes slot 2?
1possible = 32!all 32 orders are equally likely
2favorable = (32 − 2)! = 30!slots 1, 2 fixed; arrange the other 30
3P = 30! / 32!favorable ÷ possible
4= 30! / (32 · 31 · 30!)expand 32! and divide out 30!
5= 1 / 992simplify (32 · 31 = 992)
P = 1/992 ≈ 0.001 = about 0.1%
Trap: Do not reach for 32P2 and 30P30 separately unless you are consistent. Either count full arrangements top and bottom (30!/32!) or count only the first two slots (1/32P2 = 1/992). Both give 1/992 — mixing them does not.
Check: 1/32P2 = 1/(32·31) = 1/992 ✓
A slideshow plays 12 distinct photographs in random order with no repeats. Three are of the whole family, three of a brother, two of the subject, and four of a sister. What is the probability that the first four pictures shown are the four sister photos?
1order matters → permutationsthe photos will not repeat and position counts
2possible = 12P4 = 12!/(12 − 4)! = 12!/8!12 photos taken 4 at a time
3= (12 · 11 · 10 · 9 · 8!)/8! = 11,880divide out 8!
4favorable = 4! = 24the 4 sister photos in any order
5P = 24 / 11,880favorable ÷ possible
6= 1 / 495divide numerator and denominator by 24
P = 1/495 ≈ 0.002
Check: Same answer as a combination: the 4 sister photos are one specific group out of 12C4 = 11,880/4! = 495 possible groups, so P = 1/495 ✓
Five number tiles showing 2, 2, 5, 5, and 8 are arranged at random in a row. What is the probability that the row reads 2 5 8 5 2?
1n = 5; the digit 2 occurs 2 times, 5 occurs 2 times, 8 occurs 1 timeidentify the repeats
2possible = 5! / (2! · 2!)distinguishable permutations
3= 120 / 4 = 30simplify
4favorable = 1only one arrangement is the target
P = 1/30 ≈ 0.033
Trap: The denominator is not 5! = 120. Swapping the two 2s produces a row that looks identical, so those 120 arrangements only give 30 distinguishable outcomes.
Check: Choose which 2 of the 5 positions hold the 2s (5C2 = 10), then which 2 of the remaining 3 hold the 5s (3C2 = 3): 10 · 3 = 30 ✓
Ten points are named on pentagon ACEGJ: the 5 vertices A, C, E, G, J and the 5 side midpoints B, D, F, H, K. If three of the ten points are chosen at random, what is the probability that all three lie on the same line segment?
1order does not matter → combinationsa set of 3 points is a set, not a list
2possible = 10C3 = 10!/((10 − 3)! · 3!)10 points taken 3 at a time
3= (10 · 9 · 8 · 7!)/(7! · 3!) = 720/6 = 120divide out 7!
4favorable = 5the 5 sides AC, CE, EG, GJ, JA each carry 3 named points
5P = 5/120 = 1/24simplify
P = 1/24 ≈ 0.042
Check: Each side holds exactly 3 named points (two vertices and its midpoint), so it contributes exactly 3C3 = 1 favorable set. 5 sides × 1 = 5 ✓
Seven finalists give speeches in a random order. Three of them are specified in advance. (a) P(those three give the first three speeches, in any order)? (b) P(they give speeches 1, 2, 3 in one specified order)?

(a) In ANY order

possible = 7P3 = 7·6·5 = 210
favorable = 3! = 6
P = 6/210 = 1/35

Or by combinations:
possible = 7C3 = 35, favorable = 1
P = 1/35 ✓

(b) In THAT order

possible = 7P3 = 210
favorable = 1
P = 1/210

Combinations are not usable here —
the order is part of the event.
1(a) ÷ (b) = (1/35) ÷ (1/210) = 6 = 3!exactly the r! factor
(a) 1/35     (b) 1/210     ratio = 3! = 6
Trap: "In any order" makes the numerator r! (or lets you switch to combinations). "In that order" makes the numerator 1. Misreading this phrase is the single most common error in this lesson.
A set contains 15 objects of type G and 15 objects of type B (30 total). Four objects are drawn at random with no regard to order. What is the probability that all four are of type G?
1possible = 30C4 = (30·29·28·27)/(4·3·2·1)order does not matter
2= 657,720/24 = 27,405simplify
3favorable = 15C4 = (15·14·13·12)/24 = 32,760/24 = 1365all four from the 15 type-G objects
4P = 1365/27,405favorable ÷ possible
5= 13/261divide both by 105
P = 13/261 ≈ 0.0498
Trap: The answer is not (15/30)4 = 1/16. Once an object is drawn it is gone, so the draws are not independent — that is exactly why you count with combinations instead of multiplying probabilities.

Common mistakes to avoid
  • Writing 0! = 0. It equals 1.
  • Using nCr when the problem says "first", "second", or "in that order" — those need nPr.
  • Using nPr for a group with no ranking — that overcounts by a factor of r!.
  • Forgetting to divide by the repeat factorials, so 2, 2, 5, 5, 8 gets a denominator of 120 instead of 30.
  • Counting the numerator one way and the denominator another (permutations on top, combinations on the bottom).
  • Multiplying single-draw probabilities such as (15/30)4 when objects are removed and not replaced.
  • Expanding huge factorials instead of cancelling — 30!/32! is 1/(32·31), no calculator required.
  • Assuming nPr = nCr. That is true only for r = 0 or r = 1.
