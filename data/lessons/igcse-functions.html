Function notation is the language the rest of the syllabus is written in. Once $f(x)$ stops looking like a multiplication and starts looking like a machine, evaluating, solving, domain, range, composites and inverses all follow. Feed numbers into the machine below and watch what comes out.

◎ What you will be able to do

  • Read and use function notation.
  • Evaluate functions for numbers and for expressions.
  • Solve $f(x)=k$ — and know how that differs from finding $f(k)$.
  • Determine domain and range, from a formula or from a graph.
  • Work with composite and inverse functions.

1 Function notation Interactive

A function is a rule that turns each input into exactly one output.

✎
Reading the notation. $f(x)$ is read "f of x" — the output of the function $f$ when the input is $x$. It does not mean $f$ multiplied by $x$.
NotationMeaning
$f(x)=3x-5$The rule of the function
$f:x\mapsto 3x-5$The same thing — "f maps x to 3x − 5"
$f(4)$The output when the input is 4
$f(x)=10$An equation to solve — which input gives an output of 10?
$y=f(x)$The graph of the function; $y$ is the output axis
Lab 1 — the function machine

Put a value in and watch it come out the other side. Then switch to backwards mode: now you are told the output and must find the input — that is what "solve $f(x)=k$" means.

!
Watch out. Different letters are used for different functions in the same question — $f$, $g$, $h$. Keep them apart and always check which rule you are being asked to use.

2 What makes a rule a function? Interactive

Each input must give exactly one output. One input producing two outputs is not a function.

The vertical line test — if any vertical line crosses the graph more than once, it is not a function
Lab 2 — the vertical line test

Slide the vertical line across each relation and count how many times it meets the graph. One (or none) everywhere → function. Two anywhere → not a function.

3 Evaluating functions Interactive

  • Write out the rule.
  • Replace every $x$ with the given input — in brackets.
  • Work out the arithmetic in the right order.

For $f(x)=x^{2}-4x+1$:

RequiredSubstitutionResult
$f(3)$$(3)^{2}-4(3)+1=9-12+1$$-2$
$f(0)$$0-0+1$$1$

Watch out. Brackets are essential with negatives: $-4\times(-2)=+8$ and $(-2)^{2}=+4$. Dropping the brackets is the single biggest source of lost marks here.

Substituting an expression

The input does not have to be a number. For $f(x)=2x+1$:

$f(a+3)=2(a+3)+1=2a+6+1=2a+7$

Replace every $x$ with the whole expression, keeping it in brackets, then expand.

4 Solving $f(x)=k$

This reverses the process: you are given the output and must find the input.

  • Write the rule equal to the given value.
  • Solve the resulting equation for $x$.
  • If it is quadratic, rearrange to $=0$ and factorise — expect two answers.
  • Check by substituting back into the function.
✎
Example. $f(x)=3x-5$. Solve $f(x)=10$: $3x-5=10$ → $3x=15$ → $x=5$.
!
Watch out. Don't confuse $f(10)$ with $f(x)=10$. The first is "put 10 in and see what comes out"; the second is "what must go in to get 10 out?" Switch Lab 1 to backwards mode to feel the difference.
Lab 4 — solving from the graph

The curve is $f(x)=x^{2}-2x-3$. Use the presets to solve $f(x)=0$ and $f(x)=2$, and to see the case where the line just touches.

6 Composite and inverse functions Interactive

Composite $fg(x)$ — apply the inner function first, then feed its output into the outer one: $fg(x)=f(g(x))$. Work right to left, from the function nearest the $x$.
Inverse $f^{-1}(x)$ — the function that undoes $f$. Write $y=f(x)$, swap $x$ and $y$, rearrange to make $y$ the subject, rewrite as $f^{-1}(x)$.
$f(x)=2x+1$ → $x=2y+1$ → $y=\dfrac{x-1}{2}$, so $f^{-1}(x)=\dfrac{x-1}{2}$
✎
$f^{-1}$ means "inverse", not "one over $f$". The domain of $f^{-1}$ is the range of $f$.
Lab 6 — composite and inverse calculator

Choose $f$ and $g$, put a value in, and see $fg(x)$ and $gf(x)$ worked out side by side — they are almost never equal. The inverse of $f$ is built and then checked by putting the answer back through $f$.

✍️ Worked examples

Example 1
Evaluating a linear function
 ⌄

$f(x)=3x-5$. Find $f(4)$, $f(0)$ and $f(-2)$.

$f(4)=3(4)-5=12-5=7$

$f(0)=3(0)-5=0-5=-5$

$f(-2)=3(-2)-5=-6-5=-11$

Answer. $f(4)=7$ · $f(0)=-5$ · $f(-2)=-11$.
Example 2
Evaluating a quadratic — including an expression
 ⌄

$f(x)=x^{2}-2x$. Find $f(3)$, $f(-1)$ and $f(a+1)$.

1

$f(3)=(3)^{2}-2(3)=9-6=3$.

2

$f(-1)=(-1)^{2}-2(-1)=1+2=3$.

3

$f(a+1)=(a+1)^{2}-2(a+1)$. Expand: $(a^{2}+2a+1)-(2a+2)$.

4

Simplify: $a^{2}+2a+1-2a-2=a^{2}-1$.

Answer. $f(3)=3$ · $f(-1)=3$ · $f(a+1)=a^{2}-1$.
!
Subtracting the whole bracket $(2a+2)$ changes both signs inside it.
Example 3
Solving $f(x)=k$
 ⌄

$f(x)=x^{2}-2x-3$. Solve (a) $f(x)=0$ and (b) $f(x)=5$.

(a) $x^{2}-2x-3=0$ → $(x+1)(x-3)=0$ → $x=-1$ or $x=3$.

(b) $x^{2}-2x-3=5$ → rearrange to zero: $x^{2}-2x-8=0$ → $(x-4)(x+2)=0$ → $x=4$ or $x=-2$.

Check. $f(4)=16-8-3=5$ ✔ and $f(-2)=4+4-3=5$ ✔
Example 4
Domain and range from a formula
 ⌄

State the domain and range of (a) $f(x)=x^{2}+1$, (b) $g(x)=\dfrac{1}{x-2}$, (c) $h(x)=\sqrt{x-3}$.

(a) Any number can be squared, and the smallest value of $x^{2}$ is 0, giving a minimum output of 1.

Domain: all real $x$  ·  Range: $f(x)\ge1$

(b) The denominator is zero when $x=2$, which must be excluded. The fraction gets very close to zero but never equals it.

Domain: $x\neq2$  ·  Range: $g(x)\neq0$

(c) Need $x-3\ge0$, so $x\ge3$. The square root sign gives the non-negative root only.

Domain: $x\ge3$  ·  Range: $h(x)\ge0$
Example 5
Range from a restricted domain
 ⌄

$f(x)=x^{2}-4x+3$ for $0\le x\le5$. Find the range.

1

Find the turning point: $x=\frac{-b}{2a}=\frac{4}{2}=2$. It lies inside the domain, so it matters.

2

Value there: $f(2)=4-8+3=-1$ — the minimum, since $a>0$.

3

Endpoints: $f(0)=3$ and $f(5)=25-20+3=8$.

4

Largest output 8, smallest $-1$.

Answer. Range: $-1\le f(x)\le 8$.
!
Using only $f(0)$ and $f(5)$ would have given $3\le f(x)\le8$ — wrong, because the turning point dips below both endpoints.
Example 6
Reading a function from its graph
 ⌄

Using the graph of $f(x)=x^{2}-2x-3$ in Lab 4, find $f(2)$, solve $f(x)=0$, and state the range.

$f(2)$: go up from $x=2$ to the curve, then across — the value is $-3$. Check: $4-4-3=-3$ ✔

$f(x)=0$: the curve meets the x-axis at $x=-1$ and $x=3$.

Range: the lowest point is the turning point $(1,-4)$, and the curve rises indefinitely from there.

Answer. $f(2)=-3$ · $x=-1$ or $x=3$ · Range $f(x)\ge-4$.
Example 7
Composite and inverse
 ⌄

$f(x)=2x+1$ and $g(x)=x^{2}$. Find $fg(3)$, $gf(3)$ and $f^{-1}(x)$.

$fg(3)$: do $g$ first. $g(3)=9$, then $f(9)=2(9)+1=19$.

$gf(3)$: do $f$ first. $f(3)=7$, then $g(7)=49$.

$f^{-1}$: write $y=2x+1$, swap to get $x=2y+1$, rearrange: $y=\dfrac{x-1}{2}$.

Answer. $fg(3)=19$ · $gf(3)=49$ · $f^{-1}(x)=\dfrac{x-1}{2}$.
Check the inverse. $f(5)=11$ and $f^{-1}(11)=\frac{11-1}{2}=5$ ✔ — set $f=2x+1$, $g=x^{2}$, $x=3$ in Lab 6 to see all of this at once.

! Common mistakes to avoid

  • Treating $f(x)$ as multiplication. It is notation for an output, not $f\times x$.
  • Dropping brackets when substituting negatives. $f(-2)$ with $x^{2}$ gives $(-2)^{2}=4$, not $-4$.
  • Confusing $f(5)$ with $f(x)=5$. One is an evaluation, the other an equation to solve.
  • Swapping domain and range. Domain is the inputs ($x$), range the outputs ($y$).
  • Forgetting to exclude values. Check every denominator and every square root before writing a domain.
  • Doing $fg(x)$ in the wrong order. The function nearest the $x$ goes first.
  • Reading $f^{-1}(x)$ as $1/f(x)$. It means the inverse function.
