Inverse Relations and Functions

Find inverses of relations and functions, restrict domains, and verify inverses using compositions

Concepts Step-by-Step Examples Summary Practice Quiz

Key Concepts

🔑 Today's Vocabulary

inverse relations — two relations are inverse relations if one contains the element (a, b) whenever the other contains (b, a).
inverse functions — two functions f and g are inverse functions if and only if both of their compositions are the identity function.
⚠ Notation: f⁻¹ is read "f inverse" or "the inverse of f". The −1 is not an exponent — f⁻¹(x) does not mean 1/f(x).

🔑 Key Concept — Inverse Functions

If f and f⁻¹ are inverses, then f(a) = b  if and only if  f⁻¹(b) = a.

Example: let f(x) = x − 5 and represent its inverse as f⁻¹(x) = x + 5.

Evaluate f(7)

f(x) = x − 5
f(7) = 7 − 5 = 2

Evaluate f⁻¹(2)

f⁻¹(x) = x + 5
f⁻¹(2) = 2 + 5 = 7
ℹ Graphically: the graph of f⁻¹(x) is the reflection of the graph of f(x) across the line y = x.

🔑 How to Find an Inverse Function

Rewrite the function as an equation relating x and y: replace f(x) with y.
Exchange x and y in the equation.
Solve the new equation for y.
Replace y with f⁻¹(x), and restrict the domain if necessary.

🔑 When Is the Inverse a Function?

Not all functions have an inverse function. If a function fails the horizontal line test, its inverse is a relation but not a function.

Horizontal line test:  if any horizontal line crosses the graph more than once,
the function is NOT one-to-one and its inverse is NOT a function.

You can restrict the domain of the original function to a portion on which it is one-to-one. There may be more than one possible restricted domain, and each gives a different branch of the inverse.

🔑 Key Concept — Verifying Inverse Functions

Words: Two functions f and g are inverse functions if and only if both of their compositions are the identity function.

f(x) and g(x) are inverses  if and only if  [f ∘ g](x) = x  AND  [g ∘ f](x) = x
⚠ Check BOTH compositions. By definition both must simplify to the identity function x. Checking only one is not enough.

2Exchange the coordinates of each ordered pair(a, b) becomes (b, a)

4(−3, 2) → (2, −3)Swap
5(4, 1) → (1, 4)Swap
Inverse relation = {(4, 2), (2, −3), (1, 4)}
ℹ On the graph: The inverse triangle is the mirror image of the original across the line y = x.
Find the inverse of f(x) = 3x + 2. Then graph the function and its inverse.
1f(x) = 3x + 2Original function
2y = 3x + 2Step 1: rewrite, replacing f(x) with y
3x = 3y + 2Step 2: exchange x and y
4x − 2 = 3yStep 3: subtract 2 from each side
5(x − 2)/3 = yDivide each side by 3
6f⁻¹(x) = (x − 2)/3Step 4: replace y with f⁻¹(x)
f⁻¹(x) = (x − 2)/3
ℹ Step 5 — graph: Plot f(x) = 3x + 2 and f⁻¹(x) = (x − 2)/3. They are reflections of each other in the line y = x, and their slopes are reciprocals (3 and 1/3).
✓ Check: Find the inverse of f(x) = −½x + 1.  y = −½x + 1 → x = −½y + 1 → x − 1 = −½y → f⁻¹(x) = −2x + 2.
Examine f(x) = x² + 2x + 4. Part A: find the inverse. Part B: restrict the domain so the inverse is a function.

Part A: find the inverse

1f(x) = x² + 2x + 4Original function
2y = x² + 2x + 4Replace f(x) with y
3x = y² + 2y + 4Exchange x and y
4x − 4 = y² + 2ySubtract 4 from each side
5x − 4 + 1 = y² + 2y + 1Complete the square (add 1 to each side)
6x − 3 = (y + 1)²Simplify
7±√(x − 3) = y + 1Take the square root of each side
8−1 ± √(x − 3) = ySubtract 1 from each side
9f⁻¹(x) = −1 ± √(x − 3)Replace y with f⁻¹(x)
f⁻¹(x) = −1 ± √(x − 3)

Part B: restrict the domain

1f(x) fails the horizontal line testIt is a parabola with vertex at (−1, 3)
2So f⁻¹(x) is not a function as writtenThe ± produces two outputs for one input
3Restrict f(x) to a one-to-one portionSplit the parabola at its vertex, x = −1

If the domain of f is [−1, ∞)

f⁻¹(x) = −1 + √(x − 3)
(the upper branch)

If the domain of f is (−∞, −1]

f⁻¹(x) = −1 − √(x − 3)
(the lower branch)
⚠ There is more than one correct restriction. Any interval on which f is one-to-one works. The vertex is the natural splitting point for a parabola.
TEMPERATURE: A formula for converting degrees Fahrenheit to degrees Celsius is T(x) = (5/9)(x − 32). Find the inverse of T(x) and describe its meaning.
1T(x) = (5/9)(x − 32)Original function
2y = (5/9)(x − 32)Replace T(x) with y
3x = (5/9)(y − 32)Exchange x and y
4(9/5)x = y − 32Multiply each side by 9/5
5(9/5)x + 32 = yAdd 32 to each side
6T⁻¹(x) = (9/5)x + 32Replace y with T⁻¹(x)
T⁻¹(x) = (9/5)x + 32
ℹ Meaning: T⁻¹(x) converts a temperature in degrees Celsius to degrees Fahrenheit — exactly the reverse of what T(x) does.
Determine whether h(x) = √(x + 13) and k(x) = (x − 13)² are inverse functions.
1[h ∘ k](x) = h[k(x)]Composition of functions
2= h[(x − 13)²]Substitute k(x)
3= √((x − 13)² + 13)Substitute again into h
4= √(x² − 26x + 169 + 13)Distribute / expand the square
5= √(x² − 26x + 182)Simplify
6√(x² − 26x + 182) ≠ xThe composition is NOT the identity function
h(x) and k(x) are NOT inverse functions
⚠ One failed composition is enough. Because [h ∘ k](x) ≠ x, the pair fails the definition immediately — there is no need to compute [k ∘ h](x).
✓ Check: Determine whether f(x) = x/9 + 4/3 and g(x) = 9x + 12 are inverses.  [f ∘ g](x) = (9x + 12)/9 + 4/3 = x + 4/3 + 4/3 = x + 8/3 ≠ x, so they are not inverses.
GEOMETRY: The volume of a cylinder with a height of 5 inches is V = 5πr². Determine whether r = √(V/(5π)) is the inverse of the original function.

Find V ∘ r

1V = 5πr²Original function
2= 5π(√(V/(5π)))²Substitute r = √(V/(5π))
3= 5π(V/(5π))Squaring undoes the square root
4= VSimplify — identity function

Find r ∘ V

1r = √(V/(5π))Original inverse candidate
2= √(5πr²/(5π))Substitute V = 5πr²
3= √(r²)Simplify
4= rFor r ≥ 0 — identity function
Both compositions give the identity, so r = √(V/(5π)) IS the inverse of V = 5πr²
ℹ Why the domain matters: √(r²) = |r|, which equals r only when r ≥ 0. A radius is never negative, so the restriction is automatic in this context.

Summary & Common Mistakes

📝 Quick Reference

SituationWhat to doExpected result
Relation given as ordered pairsSwap each (a, b) to (b, a)The inverse relation
Linear function f(x) = mx + by → swap → solve for yf⁻¹(x) = (x − b)/m
Quadratic functionSwap, complete the square, take √ of both sides± appears — not a function yet
Inverse contains ±Restrict the domain of f at the vertexOne branch, now a function
Asked "are these inverses?"Compute [f ∘ g](x) and [g ∘ f](x)Both must equal x
Given f(a) = bApply the inverse propertyf⁻¹(b) = a
Graphing f and f⁻¹Reflect across y = xMirror-image graphs

⚠ Common Mistakes to Avoid

⚠ Reading f⁻¹(x) as a reciprocal. f⁻¹(x) is the inverse function, not 1/f(x). The −1 is notation, not an exponent.
⚠ Forgetting to swap x and y. Solving the original equation for x without exchanging the variables gives the same function back, not the inverse.
⚠ Dropping the ± sign. Taking the square root of both sides always produces ±. Keep it, then decide which branch the restricted domain selects.
⚠ Checking only one composition. The definition requires both [f ∘ g](x) = x and [g ∘ f](x) = x.
⚠ Assuming every function has an inverse function. If the graph fails the horizontal line test, restrict the domain first.
