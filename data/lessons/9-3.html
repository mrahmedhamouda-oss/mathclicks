Core Concepts

1. What a reciprocal function is

A reciprocal function is one where the variable lives in the denominator — you are dividing a fixed number by a changing expression.

f(x) = n / b(x)
where n is a real number and b(x) is a linear expression that cannot equal 0

The simplest one — the parent function — is f(x) = 1/x. Its graph is a two-piece curve called a hyperbola.

Reciprocal function — a function of the form f(x) = n/b(x), n real, b(x) linear and nonzero.
Hyperbola — the two-branch curve formed by a reciprocal function.
Excluded value — a value of x for which the function is not defined (it would make the denominator 0).
Vertical asymptote — a vertical line the graph approaches but never touches.
Horizontal asymptote — a horizontal line the graph approaches but never touches.
Domain — all inputs that are allowed; the excluded values are thrown out.
Study Tip — Alternative Notation: the parent reciprocal function can also be written f(x) = x−1.

Why no intercepts? Setting x = 0 divides by zero, so there is no y‑intercept; and 1/x can never equal 0 no matter how big x gets, so there is no x‑intercept.

3. Finding the two asymptotes

Every reciprocal function has two asymptotes, and each one comes from a different question.

Vertical asymptote — from the excluded value. Set the denominator equal to 0 and solve. If b(x) = 0 at x = c, the vertical asymptote is x = c and the domain is {x | x ≠ c}.
Horizontal asymptote — from the value f(x) can never reach. For f(x) = n/b(x) the horizontal asymptote is f(x) = 0, because no value of x makes n/b(x) equal 0.
If a constant k is added, everything slides up by k. For f(x) = n/b(x) + k the horizontal asymptote is f(x) = k and the range is {f(x) | f(x) ≠ k}.
1
Vertical asymptote ↔ domain. The excluded value is exactly the x‑value of the vertical asymptote.
2
Horizontal asymptote ↔ range. The value the graph can never output is exactly the y‑value of the horizontal asymptote.

4. Key Concept · Transformations of Reciprocal Functions

g(x) = a / (x − h) + k
ParameterEffect on the graph of f(x) = 1/x
h — horizontal translationIf h > 0, translated h units right. If h < 0, translated |h| units left. The vertical asymptote is at x = h.
k — vertical translationIf k > 0, translated k units up. If k < 0, translated |k| units down. The horizontal asymptote is at f(x) = k.
a — orientation and shapeIf |a| > 1, stretched vertically. If 0 < |a| < 1, compressed vertically. If a < 0, also reflected in the x‑axis.
Watch Out — the sign of h: the form is x − h. So 1/(x + 3) means x − (−3), giving h = −3 and a vertical asymptote at x = −3 — three units left, not right.

5. Symmetry, end behaviour and scaling

Watch Out — Symmetry: the two pieces of a reciprocal graph always sit in opposite regions around the asymptote crossing point. A function with asymptotes y = 0 and x = 0 is graphed in Quadrants I and III (when a > 0) or Quadrants II and IV (when a < 0).
Study Tip — Scaling: when graphing transformations you may need a larger coordinate plane, or you may need to scale the axes. A larger plane makes the asymptotes far more obvious.

End behaviour. As x → ±∞, the fraction a/(x − h) shrinks toward 0, so g(x) → k. As x → h, the denominator shrinks toward 0, so |g(x)| → ∞.

3
Never draw through an asymptote. Plot points on each side of the excluded value and connect them with two separate smooth curves.
4
Quadratic denominators can give two vertical asymptotes. f(x) = 3/(x² − x − 12) = 3/((x − 4)(x + 3)) is undefined at x = 4 and x = −3.

Common mistakes
  • Reading 1/(x + 3) as a shift right. It is x − (−3), so h = −3 and the shift is 3 units left.
  • Saying the horizontal asymptote is always y = 0. It is y = 0 only when there is no + k.
  • Connecting the two branches through the vertical asymptote. Never draw across it.
  • Using the numerator to find the excluded value. Only the denominator matters.
  • Forgetting that a quadratic denominator can produce two vertical asymptotes.
  • Claiming a reciprocal function has no x‑intercept when k ≠ 0 — it does.
