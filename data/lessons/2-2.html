Core Concepts

1. Absolute value is a distance, not a sign rule

The absolute value of a number is how far that number sits from zero on the number line. Distance never runs backwards, so an absolute value is never negative.

Both −4 and 4 are exactly 4 units from zero, so |−4| = |4| = 4. That single sentence is the whole lesson: every rule below is just distance in disguise.

The reading that unlocks everything: |x − a| is the distance between x and a. So |x − 3| = 5 asks “which numbers are 5 away from 3?” — and there are always two answers, one on each side: 3 − 5 = −2 and 3 + 5 = 8. You can solve a great many absolute value problems in your head this way.

2. Why every equation splits into two cases

If the distance from zero is 4, the number itself is either 4 or −4. There is no third option.

Absolute Value Equations
For any real numbers a and b, if |a| = b and b ≥ 0, then a = b or a = −b.
If b < 0, the equation has no solution.
1
Isolate. Get the absolute value bars alone on one side before you split. Splitting early is the single most common way to lose marks here.
2
Split. Set the inside equal to + the right side, and to − the right side.
3
Solve both equations separately.
4
Check each answer in the original equation. Any answer that fails is extraneous and must be thrown away.
When is checking not optional? If the right side is a plain positive number, both cases always work and checking is just good habit. But if the right side contains a variable (like 2x − 2), it can turn out negative — and an absolute value can never equal a negative. That is exactly where extraneous solutions come from, so you must check.

3. The three possible solution sets

Look at the picture in Figure 2 below and this stops being something to memorise.

Two solutions — the usual case, when the isolated absolute value equals a positive amount.
One solution — either the absolute value equals exactly 0, or one of the two cases turns out to be extraneous.
No solution — the absolute value is forced to equal a negative amount. Write the answer as ∅ or { }.

4. Vocabulary

Absolute value — distance from zero; always ≥ 0.
Extraneous solution — a value that comes out of correct algebra but fails the original equation.
Empty set — the solution set with nothing in it, written ∅ or { }.
Compound inequality — two inequalities joined by and or or.
Tolerance — in a real-world problem, the largest allowed distance from a target value.

5. Inequalities: “less than” means between, “greater than” means outside

Keep reading absolute value as distance. |x| < 5 asks for every number closer than 5 units to zero — those numbers are trapped between −5 and 5. |x| > 5 asks for every number further than 5 units away — those spill outside in both directions.

★
LessThAND — GreatOR. Less than → AND → the solution is squeezed between. Greater than → OR → the solution fans outward. Two words, and you never mix the two graphs up again.

6. Two special cases worth spotting instantly

Because an absolute value is never negative, some inequalities answer themselves:

  • |3x + 1| < −4 — a distance can never be less than a negative number. Solution set: ∅. No work needed.
  • |3x + 1| > −4 — a distance is always more than a negative number. Solution set: all real numbers. Again, no work needed.

Check the sign on the right side the moment you have isolated the absolute value. It can save you the entire question.

A bottling machine is set to fill 500 mL. A bottle passes inspection if its volume v is within 8 mL of the target. Write an absolute value inequality and find the range of acceptable volumes.
1|v − 500| ≤ 8“within 8 of 500” = distance from 500 is at most 8

Pattern to reuse: “within t of a target T” is always |measurement − T| ≤ t. The target goes inside the bars, the tolerance goes outside.

Problem 5

Solve |x + 6| ≥ 2 and graph it.
1x + 6 ≥ 2  or  x + 6 ≤ −2Greater than or equal → OR

Every rule from this lesson

|a| ≥ 0 always |a| = b → a = ±b (b ≥ 0) |x − a| = distance from a |A| < c → −c < A < c |A| > c → A > c or A < −c isolate → split → solve → check < open circle · ≤ filled circle
Common mistakes to avoid
  • Splitting into cases before the absolute value is isolated.
  • Writing −(2x + 13) as −2x + 13 — distribute to every term.
  • Skipping the check when the right side contains a variable, and keeping an extraneous answer.
  • Using AND for a “greater than” inequality, which produces an impossible empty answer.
  • Forgetting to reverse the inequality signs after dividing a compound inequality by a negative.
  • Filling in the endpoint circles for a strict < or >.
  • Doing full case work on |A| = −5 instead of writing ∅ straight away.
★
One picture to memorise: the V of y = |x| sitting on the x-axis. A horizontal line above it cuts twice, a line through the vertex touches once, a line below it misses entirely — and for inequalities, “below the line” is the segment between the crossings while “above the line” is the two rays outside them.
