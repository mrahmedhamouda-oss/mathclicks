Sets are a language before they are a topic: once you can read $\cup$, $\cap$ and the dash, a Venn diagram turns a wordy problem into a picture you can count. Build any region below and see it shaded, then fill diagrams in from the centre outwards — including the version where the overlap is unknown and you have to call it $x$.

◎ What you will be able to do

  • Use the notation $\mathcal{E}$, $\in$, $\notin$, $n(A)$, $A'$, $\cup$, $\cap$, $\subseteq$ and $\varnothing$.
  • List the elements of a region, and count them.
  • Shade a region described in set notation.
  • Use $n(A\cup B)=n(A)+n(B)-n(A\cap B)$.
  • Fill in a two-set or three-set Venn diagram, from the centre outwards.
  • Solve problems where the overlap is unknown, by calling it $x$.

1 Set notation

A set is a collection of objects, called its elements, written inside curly brackets: $A=\{2,4,6,8\}$.

SymbolRead asMeaning
$\mathcal{E}$the universal setEverything under consideration in this question
$\in$is an element ofBelongs to the set — $4\in A$
$\notin$is not an element ofDoes not belong — $5\notin A$
$n(A)$the number of elements of $A$How many things are in $A$
$A'$the complement of $A$Everything in $\mathcal{E}$ that is not in $A$
$A\cup B$$A$ union $B$In $A$ or $B$ or both
$A\cap B$$A$ intersection $B$In $A$ and $B$ — the overlap only
$A\subseteq B$$A$ is a subset of $B$Every element of $A$ is also in $B$
$\varnothing$the empty setThe set with no elements — $n(\varnothing)=0$
✎
Union or intersection? $\cup$ looks like a U for Union — it gathers everything together and makes the set bigger. $\cap$ is the other way up, and makes the set smaller.
!
Elements versus sets. $4\in A$ (an element belongs to a set) but $\{4\}\subseteq A$ (a set is contained in a set). Mixing up $\in$ and $\subseteq$ is a common lost mark.
Subsets

Every set has the empty set and itself as subsets, and a set with $n$ elements has $2^{n}$ subsets in all.

$\{p,q,r\}$ has $2^{3}=8$ subsets: $\varnothing,\ \{p\},\ \{q\},\ \{r\},\ \{p,q\},\ \{p,r\},\ \{q,r\},\ \{p,q,r\}$

2 Two-set Venn diagrams Interactive

Two sets split the universal set into four regions — $A$ only, the overlap, $B$ only, and everything outside both — and every element sits in exactly one of them.

$n(A\cup B)=n(A)+n(B)-n(A\cap B)$

You subtract the intersection because adding $n(A)$ and $n(B)$ counts the overlap twice.

Lab 1 — set notation, shaded

Type your own $\mathcal{E}$, $A$ and $B$, then pick a region. The lab lists the elements, counts them, places every element in the right part of the diagram and shades the region you asked for.

!
These two are different. $(A\cup B)'$ is outside both circles; $A'\cup B'$ is everything except the overlap. Flip between those two chips in the lab and watch the shading change.
Reading a region
  • Read the dash last. $(A\cup B)'$ means "find $A\cup B$, then take everything else".
  • $\cap$ means overlap. Shade only where both descriptions are true.
  • Check a test point in each region against the words before you commit.
✎
Two identities worth knowing: $(A\cap B)'=A'\cup B'$ and $(A\cup B)'=A'\cap B'$. Taking the complement swaps $\cup$ and $\cap$.

3 Counting problems Interactive

Phrase in the questionWhat it means
"study both"$A\cap B$
"study French only"$A\cap B'$
"study at least one"$A\cup B$
"study neither"$(A\cup B)'$
"study exactly one"the two "only" regions added
✎
Always fill the middle first. Start with $A\cap B$, subtract to get the "only" regions, then finish with the outside. Working outwards from the middle is what stops you double-counting.
When the overlap is unknown

If the question does not tell you the overlap, call it $x$, write every region in terms of $x$, then set the total equal to $n(\mathcal{E})$ and solve.

$n(A)+n(B)-x+n(\text{neither})=n(\mathcal{E})$
Lab 2 — the two-set solver

Give it the totals and one more fact. It fills every region, runs the algebra when the overlap is the unknown, and checks that the four regions add up to $n(\mathcal{E})$.

4 Three-set Venn diagrams Interactive

Three overlapping sets create eight regions.

RegionIn set notation
In all three$A\cap B\cap C$
In $A$ and $B$ but not $C$$A\cap B\cap C'$
In $A$ only$A\cap B'\cap C'$
In none of them$(A\cup B\cup C)'$
✎
The golden rule. Always start in the centre with $n(A\cap B\cap C)$ and work outwards. Each pair region is then "the pair total minus the centre", and each single region is "the set total minus the three regions already filled".
Lab 3 — the three-set diagram

The lab starts with $40$ students studying Art, Biology and Chemistry. Pick a query and the regions it uses light up — start with $n(A\cap B)$ and then $n(A\cap B\cap C')$ to see the difference for yourself.

!
The single biggest trap. $n(A\cap B)$ includes the centre. It is not just the region drawn between $A$ and $B$ — that region on its own is $n(A\cap B\cap C')$.

5 The method, every time

  • Draw the diagram and label the circles with the sets named in the question.
  • Write the number in all the sets into the centre first.
  • Work outwards, subtracting what you have already placed each time.
  • Fill in the outside region last, using the total.
  • Check that every region adds up to $n(\mathcal{E})$ — if it does not, something has been double-counted, almost always the centre.

✍️ Worked examples

Example 1
Listing sets from a universal set
 ⌄

$\mathcal{E}=\{1,2,3,\dots,12\}$, $A$ is the set of multiples of $3$ and $B$ is the set of even numbers. List $A\cap B$, $A\cup B$ and $A'$.

1

List each set: $A=\{3,6,9,12\}$ and $B=\{2,4,6,8,10,12\}$.

2

Intersection: the numbers in both lists — $\{6,12\}$.

3

Union: everything in either list, each written once, in order — $\{2,3,4,6,8,9,10,12\}$.

4

Complement: everything in $\mathcal{E}$ that is not a multiple of $3$.

Answer. $A\cap B=\{6,12\}$ · $A\cup B=\{2,3,4,6,8,9,10,12\}$ · $A'=\{1,2,4,5,7,8,10,11\}$
✎
Check. $n(A)+n(A')=4+8=12=n(\mathcal{E})$ ✓. Lab 1 opens on exactly this question.
Example 2
Using the counting formula
 ⌄

In a group of $30$ students, $18$ study French and $15$ study Spanish, and $7$ study both. How many study neither?

1

Find how many study at least one: $n(F\cup S)=18+15-7=26$.

2

Subtract from the total: $30-26=4$.

Answer. $4$ students study neither
✎
On the diagram: French only $18-7=11$, both $7$, Spanish only $15-7=8$, neither $4$. Total $11+7+8+4=30$ ✓
Example 3
Finding an unknown overlap
 ⌄

In a class of $50$, $28$ play hockey and $24$ play netball, and $6$ play neither. How many play both?

1

Let $x$ be the number who play both. Hockey only is $28-x$, netball only is $24-x$, both is $x$, neither is $6$.

2

Every student is in exactly one region, so the four regions add to $50$: $(28-x)+x+(24-x)+6=50$.

3

$58-x=50$, so $x=8$.

Answer. $8$ students play both
✎
Check. Hockey only $20$, both $8$, netball only $16$, neither $6$ → $20+8+16+6=50$ ✓. Put these numbers into Lab 2 with "I know how many are in neither".
Example 4
Reading a three-set Venn diagram
 ⌄

$40$ students study Art, Biology or Chemistry. The regions are: A only $8$, B only $7$, C only $2$, A and B only $6$, A and C only $5$, B and C only $3$, all three $4$, none $5$. Find $n(A\cap B)$, $n(B\cup C)$ and $n(A'\cap B\cap C)$.

1

$n(A\cap B)$: everything in both $A$ and $B$ — the "A and B only" region plus the centre: $6+4=10$.

2

$n(B\cup C)$: add every region inside either circle: $7+6+3+4+5+2=27$.

3

$n(A'\cap B\cap C)$: in $B$ and $C$ but not in $A$ — the "B and C only" region alone: $3$.

Answer. $n(A\cap B)=10$ · $n(B\cup C)=27$ · $n(A'\cap B\cap C)=3$
!
Answering $6$ for $n(A\cap B)$ — forgetting the centre — is the most common error in the whole topic. Lab 3 lights up both regions so you can see the difference.
Example 5
Filling in a three-set diagram
 ⌄

Of $40$ people, $22$ like tea, $20$ like coffee and $18$ like juice. $10$ like tea and coffee, $8$ like tea and juice, $7$ like coffee and juice, and $4$ like all three. How many like none of them?

1

Centre first: all three $=4$.

2

Pair regions (pair total minus the centre): tea and coffee only $=10-4=6$; tea and juice only $=8-4=4$; coffee and juice only $=7-4=3$.

3

Single regions (set total minus what is already placed): tea only $=22-(6+4+4)=8$; coffee only $=20-(6+3+4)=7$; juice only $=18-(4+3+4)=7$.

4

Add them up: $8+7+7+6+4+3+4=39$.

5

The outside: $40-39=1$.

Answer. $1$ person likes none of them
✎
Type these seven regions into Lab 3 and the $n(\mathcal{E})$ line will confirm the total of $40$.
Example 6
Describing a shaded region
 ⌄

A two-set Venn diagram has everything shaded except the overlap. Write the shaded region in set notation.

1

The unshaded part is $A\cap B$.

2

The shaded part is therefore everything else — the complement of the intersection.

Answer. $(A\cap B)'$, which can also be written $A'\cup B'$
✎
Both forms are accepted because $(A\cap B)'=A'\cup B'$. Taking the complement swaps $\cup$ and $\cap$ — pick $A'\cup B'$ in Lab 1 to see it.

! Common mistakes to avoid

  • Forgetting the centre in $n(A\cap B)$ on a three-set diagram.
  • Mixing up $\in$ and $\subseteq$. Elements belong to sets; sets are contained in sets.
  • Confusing $(A\cup B)'$ with $A'\cup B'$. The first is outside both circles; the second is everything but the overlap.
  • Adding $n(A)$ and $n(B)$ without subtracting the overlap.
  • Filling a diagram from the outside in. Always start at the centre.
  • Leaving the outside region empty. "Neither" is part of $\mathcal{E}$ and usually carries a mark.
  • Not checking the total. Every region must add to $n(\mathcal{E})$.
  • Listing an element twice in a union. Each element appears once, in order.
