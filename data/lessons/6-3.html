Key Concepts

🔑 Today's Vocabulary

nth root — for real numbers a and b and positive integer n, if aⁿ = b then a is an nth root of b.
index — the small number n written in the crook of the radical symbol, telling you which root to take.
radicand — the expression written underneath the radical symbol.
principal root — when there is more than one real root and n is even, the nonnegative root.
rational exponent — an exponent that is a fraction, such as the 1/n in b1/n.
In ∛36:   index = 3  ·  radical symbol = √  ·  radicand = 36

🔑 Key Concept — Real nth Roots

Suppose n is an integer greater than 1, b is a real number, and a is an nth root of b.

bn is EVENn is ODD
b > 01 unique positive and 1 unique negative real root: ±ⁿ√b1 unique positive and 0 negative real roots: ⁿ√b
b < 00 real roots (they are imaginary)0 positive and 1 negative real root: ⁿ√b
b = 01 real root: ⁿ√0 = 01 real root: ⁿ√0 = 0
⚠ Principal roots: Because 5² = 25, the number 25 has two square roots, 5 and −5. However √25 is 5 only. To indicate both square roots you must write ±√25.

A radical expression is simplified when the radicand contains no fractions and no radicals appear in the denominator.

🔑 Absolute Value in Radicals

When you take an even root of an even power and the result is an odd power, you must use absolute value bars so the answer is nonnegative.

⁴√(81x⁴) = ⁴√((3x)⁴) = 3|x|    (x could be negative)
√(25x⁴) = 5x²             (x² is already nonnegative — no bars needed)
ℹ Quick test: even index + even exponent inside + odd exponent outside → use absolute value.

🔑 Key Concept — Rational Exponents

An expression is in exponential form if it has the form xⁿ. It is in radical form if it contains a radical symbol.

b1/n = ⁿ√b    (except where b < 0 and n is even)
bx/y = y√(bx) = (y√b)x    for y > 1
b−n = 1 / bn

Examples

1251/3 = ∛125 = 5
1252/3 = (∛125)² = 5² = 25

Complex cases

(−49)1/2 = √(−49) = 7i
(−49)3/2 = (7i)³ = −343i
ℹ Simplest form for an expression with rational exponents requires all four: no negative exponents; no non-integer exponents in the denominator; not a complex fraction; the index of any remaining radical is as small as possible.

Try It Yourself

Evaluate or simplify each one, then reveal. Problems 4 and 5 are the absolute-value and negative-exponent traps.

Problem 1

Evaluate 81^(1/4) and 81^(3/4).
181^(1/4) = ⁴√81 = 3Because 3⁴ = 81
281^(3/4) = (⁴√81)³Denominator = the root, numerator = the power
3= 3³ = 27Take the root first, then the power — far smaller numbers
81^(1/4) = 3 and 81^(3/4) = 27
Root first, always. Doing the power first means computing 81³ = 531,441 and then its fourth root. Same answer, much harder arithmetic.

Problem 2

Write ⁵√(x³) using a rational exponent, and write y^(2/7) as a radical.
1⁵√(x³) = x^(3/5)Index 5 becomes the denominator, power 3 the numerator
2y^(2/7) = ⁷√(y²)Denominator 7 becomes the index, numerator 2 stays as the power
x^(3/5) and ⁷√(y²)
Do not swap them. x^(3/5) is the fifth root cubed, not the cube root to the fifth. The rule is index → denominator, every time.

Problem 3

Evaluate ∛(−125) and ⁴√(−16).
1∛(−125) = −5Odd index: (−5)³ = −125, so one real root exists
2⁴√(−16) has no real valueEven index: nothing real to the 4th power is negative
∛(−125) = −5, and ⁴√(−16) is not a real number (it is 2i√2 in the complex numbers)
This is Figure 2 in one line: odd index accepts negatives, even index does not.

Problem 4

Simplify √(49x⁶) and ⁴√(16x⁴). Where are absolute value bars needed?
1√(49x⁶) = 7x³… carefulEven index, even exponent inside, odd exponent outside → bars needed
2√(49x⁶) = 7|x³|If x were negative, x³ would be negative but the radical must not be
3⁴√(16x⁴) = 2|x|Even index, even exponent in, odd exponent out → bars again
7|x³| and 2|x|
Test it: at x = −2, √(49 · 64) = √3136 = 56, and 7|(−2)³| = 7(8) = 56 ✓, whereas 7x³ would give −56 ✗. By contrast √(25x⁴) = 5x² needs no bars, because x² cannot be negative.

Problem 5

Simplify 8^(−2/3).
18^(−2/3) = 1 / 8^(2/3)A negative exponent means reciprocal — it does not make the answer negative
28^(2/3) = (∛8)² = 2² = 4Root first, then power
3= 1/4Take the reciprocal
1/4
The classic error: answering −4. A negative exponent flips the base into a denominator; it never changes the sign of the result.

Problem 6

Simplify (x^(1/2) · x^(1/3)) ÷ x^(1/6).
1x^(1/2) · x^(1/3) = x^(1/2 + 1/3)Multiplying like bases adds the exponents
21/2 + 1/3 = 3/6 + 2/6 = 5/6Common denominator
3x^(5/6) ÷ x^(1/6) = x^(5/6 − 1/6)Dividing subtracts the exponents
4= x^(4/6) = x^(2/3)Reduce the fraction
x^(2/3), which is ∛(x²)
The point of rational exponents: as radicals this problem is a mess of square, cube and sixth roots. As exponents it is just adding and subtracting fractions. Convert to exponents, work, then convert back if asked.

Summary & Common Mistakes

⚠ Common Mistakes to Avoid

⚠ Writing √25 = ±5. The radical symbol alone means the principal (nonnegative) root. Use ±√25 when you want both.
⚠ Dropping absolute value bars. ⁴√(81x⁴) = 3|x|, not 3x. Without the bars the expression could be negative, which a principal even root never is.
⚠ Flipping numerator and denominator. In bx/y the numerator is the power and the denominator is the root — x4/3 = ∛(x⁴), not ⁴√(x³).
⚠ Treating a negative exponent as a negative value. 32−2/5 = 1/4, a positive number.
⚠ Multiplying exponents when you should add. x2/3 · x1/6 = x5/6, not x2/18.
