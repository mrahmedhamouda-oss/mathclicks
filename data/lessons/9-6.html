Core Concepts

1. What is a rational equation?

A rational equation is just an equation that has a variable sitting in a denominator somewhere. Because division by zero is undefined, the variable is not allowed to take every value — and that single fact drives everything else in this lesson.

Rational equation — an equation that contains at least one rational expression. Example: 7/12 + 9/(x − 4) = 55/48.
Rational inequality — an inequality that contains at least one rational expression. Example: x/2 − 5/(x + 1) > (x − 4)/3.
Excluded value — any value of the variable that makes a denominator equal 0. It can never be a solution, no matter what the algebra says.
Extraneous solution — a value produced by correct algebra that does not satisfy the original equation. In this lesson they are exactly the excluded values.
Study Tip: Write the excluded values down first, before you solve anything. If you find them at the start, checking at the end takes two seconds instead of two minutes.

2. The LCD method for rational equations

Fractions are the hard part, so we get rid of them. Multiplying every term on both sides by the least common denominator (LCD) cancels every denominator and leaves an ordinary linear or quadratic equation.

Factor every denominator and state the excluded values (set each factor equal to 0).
Find the LCD — the product of every distinct factor, each raised to the highest power it appears with.
Multiply every term on both sides by the LCD and divide out common factors. No fractions should remain.
Solve the resulting linear or quadratic equation.
Check each result against the excluded values from Step 1, then substitute into the original equation. Discard extraneous results.
If  A/D1 + B/D2 = C/D3  and LCD = L, then
L·(A/D1) + L·(B/D2) = L·(C/D3)   →   a polynomial equation

3. Why extraneous solutions appear — and how to kill them

Multiplying both sides of an equation by a number is a reversible move only when that number is not zero. The LCD contains the variable, so for certain values the LCD is zero — and at those values you have multiplied by 0, which turns a false statement into the true statement 0 = 0. The polynomial equation therefore has solutions the original equation never had.

Key Concept · Extraneous Solutions
When solving a rational equation, any possible solution that results in a zero in a denominator must be excluded from the list of solutions. Check each solution by substituting into the original equation.
!
An answer to a rational equation is not final until you have compared it to the excluded values. "Solve" always means "solve and check."
Watch Out! Extraneous does not mean you made a mistake. The algebra can be flawless and still produce an extraneous value — the LCD step manufactured it. Never "fix" your work when a result turns out extraneous; just cross it out. If every result is extraneous, the correct answer is no solution.
Talk About It: You can spot an extraneous solution without substituting: just compare each result to the excluded values you listed in Step 1. If a result equals an excluded value, it is extraneous.

4. Rational inequalities — the sign-analysis method

You cannot solve a rational inequality by multiplying by the LCD, because you do not know whether the LCD is positive or negative — and multiplying an inequality by a negative number flips the sign. Instead you find every place where the expression could change sign, split the number line there, and test each piece.

Key Concept · Solving Rational Inequalities
Step 1 State the excluded values. These are the values for which the denominator is 0.
Step 2 Solve the related equation.
Step 3 Use the values determined from the previous steps to divide a number line into intervals.
Step 4 Test a value in each interval to determine which intervals contain values that satisfy the inequality.
✓
Critical values come from BOTH places. Set the numerator equal to zero (these are the solutions of the related equation) and set the denominator equal to zero (these are the excluded values). Together they are the only points where the expression can switch from positive to negative.
Critical values = { solutions of the related equation } ∪ { excluded values }
Number line → split at every critical value → test one point per interval

Here is the interval test for x/2 − 5/(x + 1) > (x − 4)/3, whose critical values turn out to be −11, −1 and 2:

Interval x < −11

Test x = −13
LHS = −13/2 − 5/(−12) ≈ −6.08
RHS = −17/3 ≈ −5.67
−6.08 > −5.67 is FALSE

Interval −11 < x < −1

Test x = −4
LHS = −2 + 5/3 ≈ −0.33
RHS = −8/3 ≈ −2.67
−0.33 > −2.67 is TRUE ✓

Interval −1 < x < 2

Test x = 0
LHS = 0 − 5 = −5
RHS = −4/3 ≈ −1.33
−5 > −1.33 is FALSE

Interval x > 2

Test x = 3
LHS = 3/2 − 5/4 = 0.25
RHS = −1/3 ≈ −0.33
0.25 > −0.33 is TRUE ✓
Watch Out! An excluded value is always an open circle, even when the inequality uses ≤ or ≥. Only critical values that came from the numerator can be filled in for ≤ and ≥. And never cancel a variable factor from both sides of an inequality — that is the same illegal move as multiplying by an unknown sign.

Solve  x/2 − 5/(x + 1) > (x − 4)/3

Step 1 — Find the excluded values. When x = −1 the denominator x + 1 is 0, so the excluded value is x = −1.

Step 2 — Solve the related equation (replace > with =).

1x/2 − 5/(x + 1) = (x − 4)/3related equation
26(x + 1)(x/2) − 6(x + 1)·5/(x + 1) = 6(x + 1)(x − 4)/3multiply by LCD 6(x + 1)
33x(x + 1) − 30 = 2(x + 1)(x − 4)divide out common factors
43x² + 3x − 30 = 2x² − 6x − 8Distributive Property
5x² + 9x − 22 = 0standard form
6(x + 11)(x − 2) = 0factor
7x = −11  or  x = 2Zero Product Property

Steps 3 and 4 — Divide a number line into intervals and test each one. Draw vertical lines at the excluded value −1 and at the solution points −11 and 2. That makes four intervals.

(−13 − 4)/3 ≈ −5.67
false

−11 < x < −1  (test x = −4)

−4/2 − 5/(−3) ≈ −0.33
(−4 − 4)/3 ≈ −2.67
true ✓

−1 < x < 2  (test x = 0)

0/2 − 5/1 = −5
(0 − 4)/3 ≈ −1.33
false

Check against the restriction: x = −1 is excluded, so it is left out of the solution set — that is exactly why the middle piece stops at −1 with an open circle. The endpoints −11 and 2 are also open because the inequality is strict (>, not ≥).
Spot check x = −10: −5 − 5/(−9) ≈ −4.44 and (−10 − 4)/3 ≈ −4.67; −4.44 > −4.67 ✓
Watch Out! Do not just multiply the original inequality by 6(x + 1). For x < −1 that factor is negative, which reverses > to <. The related-equation-plus-testing method sidesteps that trap entirely.

Common mistakes to avoid:
  • Forgetting to check — an unchecked answer to a rational equation is not an answer.
  • Multiplying only some terms by the LCD. Every term on both sides, no exceptions.
  • Multiplying a rational inequality by the LCD. The LCD's sign is unknown, so the inequality symbol may flip. Use sign analysis instead.
  • Using only the numerator's zeros as critical values. The denominator's zeros split the line too, even though they are never solutions.
  • Filling in an endpoint that came from the denominator because the symbol was ≥. Excluded values are always open.
  • Assuming an extraneous result means you made an arithmetic error. It usually means the algebra worked exactly as expected.
  • Failing to factor a denominator such as x² − 16 first, and then guessing the wrong LCD.
