14.7  Algebraic Fractions

Simplifying, multiplying, dividing, adding and subtracting fractions with algebra in them, and solving equations that contain them.

Simplifying an algebraic fraction

An algebraic fraction is a fraction with algebra on the top, the bottom, or both. Everything you know about ordinary fractions still applies — the only new skill is that you must factorise before you can cancel.

The golden rule You may cancel a factor that appears in the whole of the top and the whole of the bottom. You may never cancel a term — something that is only part of a sum.
Watch out — the single most common error in this topic
x + 3x + 6  ≠  12
The 3 and the 6 are terms, not factors, so they cannot be cancelled. Substitute x = 5: the left side is 811 = 0.727… and the right side is 0.5. Different numbers, so the cancelling was illegal.

Allowed — cancelling a factor

3(x + 2)(x + 2)(x + 3) = 3x + 3

The bracket (x + 2) multiplies everything above and everything below, so it divides out.

Not allowed — cancelling a term

x + 2x + 3 is already in its simplest form.

The xs are joined to the numbers by +, not by ×. Nothing here is a common factor.

Method Factorise the numerator fully, factorise the denominator fully, then cancel any bracket (or number) that appears in both. If nothing factorises, the fraction is already simplest.
Example 1Simplify (a) x² − 9x² + 7x + 12  (b) 3x + 6x² + 5x + 6  (c) 2x² + 7x + 3x² − 9
1
(a) The top is a difference of two squares; the bottom needs two numbers with product 12 and sum 7. (x − 3)(x + 3)(x + 3)(x + 4)
2
Cancel the common factor (x + 3). = x − 3x + 4
3
(b) The top has a numerical common factor; the bottom factorises. 3(x + 2)(x + 2)(x + 3) = 3x + 3
4
(c) Use the ac method on the top: ac = 6, sum 7, so 6 and 1. 2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (x + 3)(2x + 1)
5
The bottom is a difference of two squares. Cancel (x + 3). (x + 3)(2x + 1)(x − 3)(x + 3) = 2x + 1x − 3
(a) x − 3x + 4    (b) 3x + 3    (c) 2x + 1x − 3
Exam tip Test your answer with a number. In (c), put x = 5 into the original: (50 + 35 + 3) ÷ (25 − 9) = 88 ÷ 16 = 5.5. Into the answer: 11 ÷ 2 = 5.5. Equal, so the simplification is safe.

Multiplying and dividing

These are the easy operations — there is no common denominator to find. Factorise everything first, cancel across the multiplication, then write what is left.

ab × cd = acbd      ab ÷ cd = ab × dc To divide, turn the second fraction upside down and multiply
Example 2Simplify x² − 4x + 1 × 3x + 3x − 2
1
Factorise every top and every bottom. (x − 2)(x + 2)x + 1 × 3(x + 1)x − 2
2
Cancel (x − 2) and (x + 1) — with multiplication you may cancel any top against any bottom. = (x + 2) × 3
3
Write the answer neatly. Leaving it factorised is fine. = 3(x + 2)   or   3x + 6
3(x + 2)
Check At x = 5 the original is (21 ÷ 6) × (18 ÷ 3) = 3.5 × 6 = 21, and 3(5 + 2) = 21. ✓
Example 3Simplify x² + 5x + 6x² − 1 ÷ x + 3x − 1
1
Turn the second fraction upside down and change ÷ to ×. x² + 5x + 6x² − 1 × x − 1x + 3
2
Now factorise. (x + 2)(x + 3)(x − 1)(x + 1) × x − 1x + 3
3
Cancel (x + 3) and (x − 1). = x + 2x + 1
x + 2x + 1
Watch out Invert only the fraction after the division sign, and do it before you start cancelling. Cancelling across a ÷ sign is not allowed.

Adding and subtracting

Fractions can only be added when they have the same denominator. With algebra the safe common denominator is the product of the two denominators, unless they share a factor.

ax + p + bx + q = a(x + q) + b(x + p)(x + p)(x + q) Cross-multiply the tops; multiply the bottoms
Watch out When you subtract, the whole of the second numerator is being taken away, so put it in a bracket: a(x + q) − b(x + p). Forgetting to change the sign of the second term inside that bracket is the classic lost mark.
Example 4Write as a single fraction (a) xx + 1 + 3x − 2  (b) 3x − 1 − 2x + 4
1
(a) The common denominator is (x + 1)(x − 2). Multiply each numerator by the denominator it is missing. x(x − 2) + 3(x + 1)(x + 1)(x − 2)
2
Expand the top only. Leave the bottom in brackets — it is more useful factorised. x² − 2x + 3x + 3 = x² + x + 3
3
The top does not factorise, so this is the final answer. = x² + x + 3(x + 1)(x − 2)
4
(b) Same start, but subtract — and bracket the second numerator. 3(x + 4) − 2(x − 1)(x − 1)(x + 4)
5
Expand carefully: −2 × (−1) = +2. 3x + 12 − 2x + 2 = x + 14
(a) x² + x + 3(x + 1)(x − 2)     (b) x + 14(x − 1)(x + 4)
Check with a number (b) at x = 5: 3 ÷ 4 − 2 ÷ 9 = 0.75 − 0.222… = 0.5278, and 19 ÷ 36 = 0.5278. ✓

Common-denominator builder

Set up a/(x + p) ± b/(x + q) and watch the single fraction being built line by line. Negative values of p and q are fine.

When the denominators share a factor Do not blindly multiply them together. Factorise first: for 4x² − 9 + 1x + 3 the bottoms are (x − 3)(x + 3) and (x + 3), so the common denominator is just (x − 3)(x + 3). See Example 6.

Equations containing algebraic fractions

To solve an equation with fractions in it, multiply every term by the common denominator. The fractions disappear and you are left with a linear or a quadratic equation you already know how to solve.

Values that are not allowed A denominator can never be zero. Before you start, write down the values of x that must be excluded: for 5x + 2 that is x ≠ −2. If a solution turns out to be an excluded value, you must reject it.

A quick linear one

Solve 5x + 2 = 3x − 1, where x ≠ −2 and x ≠ 1.

Multiply both sides by (x + 2)(x − 1) — with a single fraction each side this is the same as cross-multiplying:

5(x − 1) = 3(x + 2)  →  5x − 5 = 3x + 6  →  2x = 11  →  x = 5.5

Check: 5 ÷ 7.5 = 0.6̇ and 3 ÷ 4.5 = 0.6̇. ✓

Example 5Solve 1x + 1x + 1 = 56
1
State the excluded values first. x ≠ 0  and  x ≠ −1
2
The common denominator of all three terms is 6x(x + 1). Multiply every term by it and cancel. 6(x + 1) + 6x = 5x(x + 1)
3
Expand both sides. 6x + 6 + 6x = 5x² + 5x
12x + 6 = 5x² + 5x
4
Collect on the side that keeps x² positive. 0 = 5x² − 7x − 6
5
Factorise: ac = −30, sum −7 → −10 and 3. 5x² − 10x + 3x − 6 = 5x(x − 2) + 3(x − 2) = (x − 2)(5x + 3)

More worked examples

Example 6Write 4x² − 9 + 1x + 3 as a single fraction in its simplest form.
1
Factorise the first denominator — it is a difference of two squares. 4(x − 3)(x + 3) + 1x + 3
2
The second denominator is already inside the first, so the common denominator is (x − 3)(x + 3). Only the second fraction needs adjusting. 4(x − 3)(x + 3) + x − 3(x − 3)(x + 3)
3
Add the numerators. 4 + x − 3 = x + 1
x + 1(x − 3)(x + 3)
Check At x = 5: 4 ÷ 16 + 1 ÷ 8 = 0.375 and 6 ÷ (2 × 8) = 0.375. ✓ Using the product (x² − 9)(x + 3) would have worked too, but you would then have to cancel (x + 3) at the end to gain the final mark.
Example 7Solve 3x + 1 + 4x − 2 = 2, giving your answers correct to 2 decimal places.
1
Excluded values: x ≠ −1 and x ≠ 2. Multiply every term by (x + 1)(x − 2). 3(x − 2) + 4(x + 1) = 2(x + 1)(x − 2)
2
Expand each side. 3x − 6 + 4x + 4 = 2(x² − x − 2)
7x − 2 = 2x² − 2x − 4
3
Rearrange to … = 0. 0 = 2x² − 9x − 2
4
No integer pair multiplies to −4 and adds to −9, so use the formula with a = 2, b = −9, c = −2. x = 9 ± √(81 + 16)4 = 9 ± √974
5
Work out both values, rounding only at the end. √97 = 9.8489…
x = 18.8489 ÷ 4 = 4.712…  or  x = −0.8489 ÷ 4 = −0.2122…
x = 4.71  or  x = −0.21 (2 d.p.)
Watch out Do not round √97 to 9.85 and then divide — keep the full calculator value until the very last step, or the second decimal place can come out wrong. Both answers are needed; a single root scores half the marks.

Practice set

  1. Simplify x² − 16x² − x − 12.
  2. Simplify 2x² − 8x² + 4x + 4.
  3. Write as a single fraction: 2x + 3 + 5x − 1.
  4. Simplify x² − 1x + 2 × 3x + 6x − 1.
  5. Solve x + 12x = 8.
  6. Solve 5x − 1 − 2x + 2 = 1, giving your answers to 2 decimal places.

  1. (x − 4)(x + 4)(x − 4)(x + 3) → x + 4x + 3
  2. 2(x − 2)(x + 2)(x + 2)² → 2(x − 2)x + 2
  3. 2(x − 1) + 5(x + 3) = 2x − 2 + 5x + 15 → 7x + 13(x + 3)(x − 1)
  4. (x − 1)(x + 1)x + 2 × 3(x + 2)x − 1 → 3(x + 1)
  5. Multiply by x (x ≠ 0): x² + 12 = 8x → x² − 8x + 12 = 0 → (x − 2)(x − 6) = 0 → x = 2 or x = 6
  6. x ≠ 1, x ≠ −2. 5(x + 2) − 2(x − 1) = (x − 1)(x + 2) → 3x + 12 = x² + x − 2 → x² − 2x − 14 = 0 → x = 2 ± √602 → x = 4.87 or x = −2.87

Key points to remember

  • Factorise first, cancel second. Nothing can be cancelled until top and bottom are products.
  • Cancel factors, never terms: x + 3x + 6 does not simplify at all.
  • To divide, invert the second fraction and multiply — then cancel.
  • To add or subtract, use (x + p)(x + q) as the denominator, unless the denominators share a factor, in which case factorise and use the smaller common denominator.
  • When subtracting, bracket the second numerator before you expand.
  • Expand the numerator, but leave the denominator in factorised form.
  • To solve, multiply every term by the common denominator, rearrange to … = 0, then factorise or use the formula.
  • Always state the values of x that make a denominator zero, and reject any solution that matches one. Substitute your answers back to check.
