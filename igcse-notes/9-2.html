9.2  Rational and Irrational Numbers

What makes a number rational, how to prove it, which roots are irrational, and what happens when you add or multiply the two kinds together.

Definitions Recognising Combining In between Examples Your turn Key points

The two kinds of real number

Every real number is either rational or irrational — there is no third option and no overlap. The whole topic rests on one definition, so learn it word for word.

Definition A number is rational if it can be written as ab where a and b are integers and b ≠ 0. The set of rationals is written ℚ. A number that cannot be written this way is irrational.

Notice what the definition does not say. It does not say the number must look like a fraction — only that it could be written as one. That is why 7, −3, 0.25 and 0.3̇ are all rational.

The decimal test

Convert to a decimal and look at the tail:

  • It stops → rational.
  • It repeats a block for ever → rational.
  • It goes on for ever with no repeating block → irrational.

Your calculator only shows about ten digits, so it can never prove irrationality on its own. Use it as a hint, then justify with algebra.

Watch out 22/7 = 3.142857… is a fraction, so it is rational. It is only an approximation to π, which is irrational. A number does not become irrational just because it is close to one.

Recognising and proving

Roots

√n is rational ⇔ n is a perfect square 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, …

So √36 = 6 is rational, while √37 is irrational. The same idea applies to cube roots: 3√27 = 3 is rational, 3√30 is not. Fractions under the root work too: √(4/9) = 2/3 is rational because both 4 and 9 are perfect squares.

Why √2 cannot be a fraction

Suppose it could. Then √2 = a/b for integers with the fraction already in its lowest terms. Squaring gives 2 = a²/b², so a² = 2b². That makes a² even, so a is even, say a = 2k. Substituting, 4k² = 2b², so b² = 2k² and b is even as well. But then a and b share a factor 2, contradicting “lowest terms”. The assumption must be wrong, so √2 is irrational. The same argument works for every non-square.

Proving a decimal is rational

To prove a recurring decimal is rational you must produce the fraction. The standard method is worth two or three marks, so show every line.

Example 1Show that 0.5̇4̇ is a rational number.
1

2
The repeating block has two digits, so multiply by 10² = 100. 100x = 54.545454…
3
Subtract — the infinite tails are identical and cancel exactly. 100x − x = 54.5454… − 0.5454…
99x = 54
4

5

Why rational + irrational must be irrational

Let r be rational and x irrational, and suppose the sum r + x were rational, equal to s say. Then x = s − r. But the difference of two rationals is rational (a common denominator makes it one fraction of integers), so x would be rational — which it is not. The supposition fails, so r + x is irrational.

Example 3Let p = 3 + √5 and q = 3 − √5. Show that p + q and pq are both rational, but p and 2p are not.
1
Add. The surd parts cancel. p + q = (3 + √5) + (3 − √5) = 6
2
Multiply. This is a difference of two squares, (a + b)(a − b) = a² − b². pq = 3² − (√5)² = 9 − 5 = 4
3
Both results are integers, so both are rational.
4
p itself is rational + irrational, so it is irrational; and 2p = 6 + 2√5 is a non-zero rational times an irrational added to a rational, so it is irrational too. p = 5.2360…   2p = 10.4721… (never repeat)
p + q = 6 and pq = 4 are rational; p and 2p are irrational
Note A pair like 3 + √5 and 3 − √5 is called a pair of conjugates. Their sum and product are always rational — the fact that makes rationalising denominators work in section 9.3.

Combination tester

Build two numbers of the form p + q√r and combine them. Try p₁ = 2, q₁ = 1 with p₂ = 2, q₂ = −1 and r = 3 under ×.

Finding a number in a given interval

“Write down an irrational number between 4 and 5” is worth one easy mark, provided you know the two standard tricks.

A rational number in an interval

Take the midpoint, or any convenient decimal that sits inside. Between 4 and 5: 4.5, or 9/2. Between √2 = 1.414… and √3 = 1.732…: 1.5.

Always check both inequalities before writing it down.

An irrational number in an interval

Method 1 — square the ends. Between 4 and 5, square to get 16 and 25. Any integer strictly between them that is not a perfect square gives an irrational root: √17, √18, …, √24.

Method 2 — build a decimal. Write a decimal inside the interval whose digits follow a non-repeating pattern, e.g. 4.1010010001… Say in words that the pattern never repeats.

Exam tip If the interval is narrow, Method 1 may fail (there is no integer square root between 2.1 and 2.2), so keep Method 2 in reserve. A multiple of π also works when it lands in range, for example π ≈ 3.1416 lies between 3 and 3.2.

More worked examples

Example 4State, with a reason, whether each is rational or irrational: (a) √2 × √18 (b) √3 + √12 (c) √5 ÷ √20 (d) (1 + √2)²
1
(a) Combine the roots: √a × √b = √(ab). √2 × √18 = √36 = 6 An integer, so rational.
2
(b) Simplify √12 = √4 × √3 = 2√3. √3 + 2√3 = 3√3 A non-zero rational times an irrational, so irrational.
3
(c) Divide under one root: √a ÷ √b = √(a/b). √(5/20) = √(1/4) = ½ Rational.
4
(d) Expand the square carefully — there is a middle term. (1 + √2)² = 1 + 2√2 + 2 = 3 + 2√2 Rational + irrational, so irrational.
(a) rational   (b) irrational   (c) rational   (d) irrational
Watch out (1 + √2)² is not 1 + 2. Squaring a bracket never means squaring each term separately.

Example 6x is rational and y is irrational. For each expression state whether it is always rational, always irrational, or could be either, giving an example: x + y, xy, y², y − y.
1
x + y: if it were rational, y = (x + y) − x would be a difference of rationals, hence rational. Contradiction. always irrational, e.g. 5 + √2
2
xy: the same argument works when x ≠ 0, dividing instead of subtracting. But x is allowed to be 0. 0 × √2 = 0 (rational)    3 × √2 (irrational) So it could be either — irrational unless x = 0.
3
y²: squaring can destroy a root, or leave one. (√2)² = 2 (rational)    π² (irrational) Could be either.
4
y − y = 0 whatever y is. always rational
x + y irrational · xy either · y² either · y − y rational

Key points to remember

  • Rational means “can be written as a/b with a, b integers and b ≠ 0”. Everything else is irrational.
  • Terminating and recurring decimals are always rational; a decimal with no repeating block is irrational.
  • √n is rational exactly when n is a perfect square; otherwise it is irrational. Simplify roots before you classify.
  • To prove a recurring decimal is rational, multiply by 10k (k = length of the recurring block), subtract, and state the resulting fraction.
  • rational + irrational is always irrational; non-zero rational × irrational is always irrational.
  • irrational + irrational and irrational × irrational can be either — always test with an example such as √2 × √8 = 4.
  • Conjugates such as a + b√c and a − b√c have a rational sum and a rational product.
  • For an irrational number in an interval, square the bounds and pick a non-square between them; if none exists, build a non-repeating decimal and say that it never repeats.
