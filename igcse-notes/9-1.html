9.1  Sequences

Term-to-term and position-to-term rules, the nth term of linear and quadratic sequences, and the patterns of shapes they come from.

Terms, positions and rules

A sequence is a list of numbers in a definite order. Each number is a term, and each term has a position — first, second, third and so on. We write the term in position n as Tn or simply “the nth term”.

Term-to-term rule

Tells you how to get from one term to the next. It is useless on its own — you must also state the first term.

3, 7, 11, 15, …

“Start at 3 and add 4 each time.”

Fine for finding the 6th term. Hopeless for the 200th.

Position-to-term rule

A formula in n that gives any term straight away. This is what examiners mean by “find the nth term”.

Tn = 4n − 1

n = 1: 3, n = 2: 7, n = 200: 799 — one substitution, no listing.

Watch out “Add 4 each time” earns no marks when the question asks for the nth term. The answer must be an expression containing n.
Definition The nth term of a sequence is a formula in n such that substituting n = 1, 2, 3, … generates the terms in order. Positions always start at n = 1, never 0.

Term generator

Set the coefficients of an² + bn + c and watch the sequence appear. Try a = 0, b = 4, c = −1, then a = 1, b = 0, c = 3.

Linear sequences

A sequence is linear (or arithmetic) when the difference between consecutive terms is always the same. That constant difference is called d, and the first term is a.

nth term = dn + (a − d) d = common difference  ·  a = first term

Why it works: the coefficient of n must be d, because every step of 1 in position produces a step of d in value. Then a − d is the “zero term” — what would sit in front of the first term if the pattern were extended backwards.

1

Using the rule backwards: is this number in the sequence?

To test whether a value k appears, set the nth term equal to k and solve for n. If n comes out as a positive whole number, the value is a term and n tells you which one. Any fraction or negative means it is not in the sequence.

Example 2A sequence begins 20, 17, 14, 11, … (a) Find the nth term. (b) Is −7 a term? (c) Is 0 a term?
1
(a) The difference is negative but still constant. d = −3,   a = 20
Tn = −3n + (20 − (−3)) = −3n + 23
2
Check: n = 1 gives −3 + 23 = 20 ✓ and n = 4 gives −12 + 23 = 11 ✓
3
(b) Set the rule equal to −7 and solve. −3n + 23 = −7
−3n = −30
n = 10
4
(c) Now try 0. −3n + 23 = 0  →  n = 23/3 = 7.67… Not a whole number, so 0 never appears.
(a) 23 − 3n   (b) yes, the 10th term   (c) no
Exam tip Always write the sentence “n is not a positive integer, so it is not a term”. The reasoning carries the mark, not just the word “no”.

Sequences from patterns

Pattern questions are linear sequences in disguise. Count the shapes or matchsticks, list the numbers, then use the same method. The constant difference is whatever each new copy of the pattern adds.

Squares made from matchsticks

Example 3For the matchstick patterns above, (a) find the number of matches in pattern n, (b) find which pattern uses exactly 61 matches.
1
(a) List the counts and difference them. 4   7   10   13
  +3  +3  +3  →  d = 3, a = 4
2
Apply the formula. Tn = 3n + (4 − 3) = 3n + 1 This matches the picture: one match to start the row, then 3 for every square.
3
(b) Solve 3n + 1 = 61. 3n = 60  →  n = 20
(a) 3n + 1   ·   (b) pattern 20

Quadratic sequences

If the first differences are not constant, difference them again. When the second differences are constant the sequence is quadratic: its nth term has the form an² + bn + c.

a = second difference2 then subtract an² from the sequence and finish with the linear method

The three-step method

  1. Second difference ÷ 2 gives a.
  2. Work out an² for n = 1, 2, 3, … and subtract it from the original terms.
  3. What is left is always a linear sequence — find its rule bn + c and add it on.
Example 4A sequence is 3, 8, 15, 24, 35, … (a) Find the nth term. (b) Show that 168 is a term and say which one.
1
Build the difference table. terms:  3   8   15   24   35
1st:    5   7    9    11
2nd:     2   2    2
2
Second difference 2, so a = 2 ÷ 2 = 1; the n² part is 1n². n²:  1, 4, 9, 16, 25
3
Subtract n² from the terms. 3−1, 8−4, 15−9, 24−16, 35−25
= 2, 4, 6, 8, 10
4
That leftover is linear with d = 2 and first term 2, so it is 2n. Add the two parts. Tn = n² + 2n
5
Check n = 4: 16 + 8 = 24 ✓
6
(b) Solve n² + 2n = 168 as a quadratic equation. n² + 2n − 168 = 0
(n + 14)(n − 12) = 0
n = −14 or n = 12 A position must be positive, so n = 12.
(a) Tn = n² + 2n   ·   (b) 168 is the 12th term
Watch out Do not stop at the second difference and write “a = 2”. You must halve it. Halving is the single most-forgotten step in this topic.
Note Quadratic sequences come from two-dimensional patterns — areas, arrays of dots, numbers of diagonals, handshakes. If a pattern grows in two directions at once, expect an n². For example 1, 3, 6, 10, 15 (triangular numbers) has second difference 1, giving a = ½ and Tn = ½n² + ½n = n(n + 1)2.

Cubic, geometric and Fibonacci-style sequences

Cubic sequences

If the third differences are constant the rule involves n³, and the coefficient of n³ is the third difference ÷ 6.

2, 9, 28, 65, 126

1st: 7, 19, 37, 61  ·  2nd: 12, 18, 24  ·  3rd: 6, 6

6 ÷ 6 = 1, and subtracting n³ leaves 1, 1, 1, 1, 1, so Tn = n³ + 1.

Geometric (exponential) sequences

Here you multiply by a constant ratio r each time, so the differences never settle. Divide consecutive terms to find r.

Tn = ar n−1

3, 6, 12, 24, …

r = 6 ÷ 3 = 2, a = 3, so Tn = 3 × 2 n−1. Check n = 4: 3 × 2³ = 24 ✓

Fibonacci-style sequences

Some sequences are defined only by a term-to-term rule that uses two previous terms:

Tn+2 = Tn+1 + Tn each term is the sum of the two before it

The Fibonacci sequence itself is 1, 1, 2, 3, 5, 8, 13, 21, … There is no simple nth term at IGCSE, so questions instead ask you to continue the sequence or to find a missing early term using algebra.

Typical question. The first term is 4, the third term is 11 and each term after the second is the sum of the two before it. Let the second term be x: then the third term is 4 + x = 11, so x = 7 and the sequence is 4, 7, 11, 18, 29, …

Exam tip Before reaching for differences, glance at the terms. If they double, triple or halve, the sequence is geometric and no amount of differencing will help. If they are close to the square numbers 1, 4, 9, 16 or the cubes 1, 8, 27, 64, compare with those directly — 2, 5, 10, 17 is simply n² + 1.

1
Difference table. terms: 2   9   20   35   54
1st:   7   11   15   19
2nd:    4    4    4
2
Second difference 4, so a = 4 ÷ 2 = 2. 2n²:  2, 8, 18, 32, 50
3
Subtract. 2−2, 9−8, 20−18, 35−32, 54−50
= 0, 1, 2, 3, 4

The leftover is linear with d = 1, first term 0, so it is 1n + (0 − 1) = n − 1. Tn = 2n² + n − 1

Example 6A sequence is 5, 10, 20, 40, … (a) Write down the nth term. (b) Find the 10th term. (c) Which term equals 1280?
1
The differences 5, 10, 20 are not constant, but each term is double the one before. 10 ÷ 5 = 2,   20 ÷ 10 = 2,   40 ÷ 20 = 2  →  r = 2
2
(a) Use ar n−1 with a = 5. Tn = 5 × 2 n−1
3
(b) Substitute n = 10. The power is n − 1 = 9, not 10. T10 = 5 × 29 = 5 × 512 = 2560
4
(c) Solve 5 × 2 n−1 = 1280. 2 n−1 = 256 = 28
n − 1 = 8  →  n = 9
(a) 5 × 2 n−1  ·  (b) 2560  ·  (c) the 9th term
Watch out Writing 5 × 2n gives 10 for the first term. The exponent must be n − 1 so that n = 1 returns the first term.
Example 7The first four terms of a sequence are 12, 25, 38, 411. Find the nth term and the 10th term.
1
Treat the numerators and denominators as two separate sequences. numerators: 1, 2, 3, 4
denominators: 2, 5, 8, 11
2
Numerators: d = 1, a = 1, so the rule is n.
3
Denominators: d = 3, a = 2. 3n + (2 − 3) = 3n − 1
4
Put them back together and test with n = 3. Tn = n / (3n − 1)
n = 3: 3/(9 − 1) = 3/8 ✓
5
Substitute n = 10. 10/(30 − 1) = 10/29
Tn = n3n − 1   ·   T10 = 1029
Exam tip Whenever a sequence of fractions appears, split it in two. Paper 4 uses this structure regularly, sometimes with a quadratic on the bottom.

Your turn

Practice set

  1. Find the nth term of 9, 13, 17, 21, … and the 50th term.
  2. A sequence begins 100, 93, 86, 79, … Find the nth term and show whether 2 is a term.
  3. Find the nth term of 4, 7, 12, 19, 28, …
  4. Find the nth term of 0, 7, 18, 33, 52, …
  5. In a sequence, each term after the second is the sum of the two terms before it. The first term is 1 and the fourth term is 11. Find the second term.
  6. Triangles are made from matchsticks in a row: pattern 1 uses 3, pattern 2 uses 5, pattern 3 uses 7. (a) Find the number of matches in pattern n. (b) Which pattern uses 99 matches? (c) Explain why no pattern uses exactly 100 matches.

  1. d = 4, a = 9 → 4n + (9 − 4) = 4n + 5; T50 = 200 + 5 = 205
  2. d = −7, a = 100 → 107 − 7n. Then 107 − 7n = 2 → 7n = 105 → n = 15, a positive integer, so yes, the 15th term
  3. 1st differences 3, 5, 7, 9; 2nd difference 2 → a = 1. Subtract n²: 3, 3, 3, 3, 3 → n² + 3
  4. 1st differences 7, 11, 15, 19; 2nd difference 4 → a = 2. Subtract 2n²: −2, −1, 0, 1, 2, which is n − 3 → 2n² + n − 3
  5. Let the second term be x: terms are 1, x, 1 + x, 1 + 2x. So 1 + 2x = 11 → x = 5 (sequence 1, 5, 6, 11)
  6. (a) d = 2, a = 3 → 2n + 1  (b) 2n + 1 = 99 → n = 49  (c) 2n + 1 is always odd, and 100 is even, so no pattern uses 100 matches

Key points to remember

  • A term-to-term rule needs the first term as well; a position-to-term rule (the nth term) works for any position on its own.
  • Constant first differences → linear: Tn = dn + (a − d).
  • Constant second differences → quadratic: halve the second difference to get a, subtract an², then finish the leftover linear part.
  • Constant third differences → cubic, with the coefficient of n³ equal to the third difference ÷ 6.
  • Multiplying by a constant ratio → geometric: Tn = ar n−1 — the power is n − 1.
  • To test whether a number is in a sequence, set the nth term equal to it and solve; only a positive integer value of n counts.
  • Always substitute n = 1 and one later value back into your rule before writing the final answer.
  • For pattern questions, count the shapes first, write the number sequence, then use the ordinary methods.
