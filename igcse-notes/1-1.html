1.1  Different Types of Numbers

Natural numbers, integers, rationals, irrationals and reals — the language and notation you are expected to use throughout the whole course.

Number sets Notation Special numbers Recurring decimals Examples Your turn Key points

The number sets

Every number you meet in IGCSE belongs to one or more number sets. Learning the names and the symbols now saves you marks later, because Paper 2 and Paper 4 questions often say things like “write down an irrational number between 3 and 4” without any further explanation.

SetSymbolWhat it containsExamples
Natural numbersℕCounting numbers, starting at 11, 2, 3, 4, …
Whole numbers—Natural numbers together with 00, 1, 2, 3, …
IntegersℤPositive and negative whole numbers and 0−3, −2, −1, 0, 1, 2
Rational numbersℚAny number that can be written as ab where a and b are integers and b ≠ 0¾, −5, 0.25, 0.3̇
Irrational numbers—Numbers that cannot be written as a fraction; their decimals never stop and never repeat2, π, 7
Real numbersℝAll rationals and all irrationals together — every point on the number lineeverything above
Key idea The sets are nested: every natural number is an integer, every integer is rational, and every rational number is real. Only the irrationals sit outside ℚ.

Number classifier

Type any number and see exactly which sets it belongs to. Try 7, -4, 0.375, 3/8, sqrt2, sqrt16 or pi.

Notation you must recognise

Set membership

  • 5 ∈ ℕ — “5 is an element of the natural numbers”
  • −5 ∉ ℕ — “−5 is not a natural number”
  • ℤ ⊂ ℚ — “the integers are a subset of the rationals”

Comparing numbers

  • a = b equal  ·  a ≠ b not equal
  • a < b less than  ·  a > b greater than
  • a ≤ b less than or equal to
  • a ≥ b greater than or equal to
  • a ≈ b approximately equal to
Watch out With negative numbers the inequality can feel backwards: −7 < −2 is true, because −7 is further to the left on the number line. Always picture the line.

Special types of number

Square numbers

1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144

A number multiplied by itself: n².

Cube numbers

1, 8, 27, 64, 125, 216, 1000

A number multiplied by itself three times: n³.

Triangular numbers

1, 3, 6, 10, 15, 21, 28

Formed by 1, 1+2, 1+2+3, … — the nth term is n(n+1)2.

Reciprocals

The reciprocal of a is 1a; the reciprocal of ab is ba. A number times its reciprocal always gives 1. Zero has no reciprocal.

Recurring decimals and fractions

A rational number always produces a decimal that either terminates (0.625) or recurs (0.272727… = 0.2̇7̇). The dots go above the first and last digit of the repeating block.

0.3̇ = 13    0.1̇2̇ = 433    0.1̇6̇7̇ = 167999 Recurring decimals are always rational
Example 1Write 0.4̇5̇ as a fraction in its lowest terms.
1
Call the decimal x. x = 0.454545…
2
Two digits repeat, so multiply by 10² = 100. 100x = 45.454545…
3
Subtract the first line from the second — the tails cancel exactly. 100x − x = 45.4545… − 0.4545…
99x = 45
4
Divide and simplify (divide top and bottom by 9). x = 45/99 = 5/11
0.4̇5̇ = 511
Example 2Write 0.16̇ (only the 6 recurs) as a fraction.
Careful Here one digit does not recur, so you need two multiplications before subtracting.
1
x = 0.16666…
2
Multiply by 10 to push the non-recurring digit past the point. 10x = 1.6666…
3
Multiply by 100 so the recurring tails line up. 100x = 16.6666…
4
Subtract the smaller from the larger. 100x − 10x = 16.666… − 1.666…
90x = 15
5
x = 15/90 = 1/6
0.16̇ = 16

More worked examples

Example 3From the list −6,  0,  √9,  √10,  3.75,  π,  22/7 write down (a) the integers, (b) the irrational numbers.
1
Simplify anything you can first. √9 = 3  →  this is an integer, not irrational
2
(a) Integers are whole numbers, positive, negative or zero. −6,  0,  √9
3
(b) Irrational numbers cannot be written as a fraction. 3.75 = 15/4 and 22/7 are both fractions, so they are rational. √10  and  π
(a) −6, 0, √9     (b) √10, π
Exam trap 22/7 is only an approximation to π. It is a fraction, so it is rational — π itself is not.
Example 4Insert one number in each gap so that both statements are true: √__ ∈ ℤ and √__ ∉ ℚ, using values between 20 and 30.
1
For √n to be an integer, n must be a perfect square. Between 20 and 30 the only perfect square is 25. √25 = 5 ∈ ℤ  ✓
2
For √n to be irrational, n must not be a perfect square. Any other value works, for example 26. √26 = 5.0990… ∉ ℚ  ✓
√25 ∈ ℤ   and   √26 ∉ ℚ
Example 5Show that 0.9̇ is exactly equal to 1.
1
x = 0.9999…
2
One digit recurs, so multiply by 10. 10x = 9.9999…
3
Subtract. 9x = 9  →  x = 1
0.9̇ = 1
Why this matters It shows a number can have two decimal names. The algebra is identical to Examples 1 and 2, so if you can do this you can do any recurring-decimal question.

Your turn

Practice set

  1. State whether each is rational or irrational: (a) √36  (b) √12  (c) 0.8̇1̇  (d) 2π
  2. Write 0.7̇ as a fraction in its lowest terms.
  3. Write 0.2̇4̇ as a fraction in its lowest terms.
  4. Write down an irrational number between 4 and 5.
  5. True or false: −9 ∈ ℕ.

  1. (a) rational (= 6)  (b) irrational  (c) rational (recurring)  (d) irrational
  2. 10x = 7.77…, x = 0.77… → 9x = 7 → 7/9
  3. 100x = 24.2424… → 99x = 24 → 24/99 = 8/33
  4. Any non-perfect-square root in range, e.g. √17 (√16 = 4, √25 = 5).
  5. False — the natural numbers contain no negatives.

Key points to remember

  • ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ — the sets sit inside one another.
  • A number is rational if it can be written as a fraction of two integers. Terminating and recurring decimals are both rational.
  • A root is irrational only when the number under it is not a perfect square — √9 is an integer, √10 is not.
  • To convert a recurring decimal: let x be the decimal, multiply by 10ⁿ where n is the length of the recurring block, then subtract.
  • If some digits do not recur, multiply twice so the recurring tails line up before subtracting.
  • Always simplify surds and roots before classifying a number.
